# 战斗动作结构参考

## 1. 拳脚近战

- 用脚步和重心启动动作，不让拳脚从静止姿态凭空出现。
- 连击按“试探或封线 -> 主攻 -> 防守反馈 -> 变线或退出”组织。
- 上肢连击穿插重心、支撑脚和躯干旋转，避免只有手臂摆动。
- 防守方必须逐击给出格挡、拍拨、侧闪、后仰、下潜或退步中的明确选择。

示例骨架：前脚切入外侧 -> 前手封住对方视线和拳路 -> 后手直拳逼迫格挡 -> 对方前臂外拨 -> 攻方借回弹收肘并退出半步。

## 2. 兵器交锋

- 锁定双方惯用手、握法、刃口方向、武器长度和安全距离。
- 每次碰撞写清攻击轨迹、格挡角度、接触点和反震方向。
- 长兵器优先中景展示完整轨迹，贴身后切近景表现换握、压刃或脱离。
- 不让武器在镜头间无动作换手、消失或改变长度。

示例骨架：角色A右手横斩胸线 -> 角色B双手抬刀斜架 -> 两刃在B左肩外侧接触 -> B顺反震后撤半步并保持刀尖指向A。

## 3. 摔投与擒拿

- 先建立物理邻接，再描述抓握。
- 明确抓握点、支撑脚、髋肩位置、重心越过支点的过程和落地方向。
- 复杂关节控制拆成“抓握 -> 破坏平衡 -> 转体/下压 -> 落地结果”。
- 地面缠斗优先局部动作与结果确认，避免同时描述多条肢体链。

## 4. 追逐与位移

- 记录起始距离、路线、速度差和每次障碍后的距离变化。
- 跳跃、滑铲、攀爬和急转弯必须有起跳点、接触点与落点。
- 镜头可用追尾、侧向跟拍或高位路径确认，但同一镜头不要同时环绕和穿梭。
- 终点必须由抓住、逃脱、被阻挡或进入新空间等可见结果确认。

## 5. 能力交锋

- 为每个能力建立源点、颜色、形态、范围、速度、持续时间和消耗。
- 先写角色动作，再写能力生成，然后写传播、接触、抵消或命中结果。
- 对冲效果明确接触面、压力方向、粒子流向和哪一方逐渐占优。
- 能力没有远程传播设定时，不自动生成冲击波、剑气或光束。

## 6. 多人战斗

- 优先拆成局部一对一或一对二关系，避免所有人同帧高速混战。
- 建立前景、中景、背景与左右站位，记录每个人当前对手和行动目标。
- 群体包围通过多个短镜头确认，不让背景人物无解释消失。
- 角色切换对手前，用视线、转身、位移或镜头过渡明确交接。

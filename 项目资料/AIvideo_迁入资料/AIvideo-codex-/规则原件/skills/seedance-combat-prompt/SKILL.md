# 通用 3D 动漫战斗动作设计

将当前项目中的战斗剧情转化为物理可见、因果清晰、适配目标 AI 视频模型的动作方案。严格继承当前项目角色、武器、能力、胜负、伤势、场地和美术设定，不携带其他项目的角色卡、招式、能量颜色或世界观。

## 职责边界

- 负责：起势、攻防动作链、转折、终结、力学传导、动作衔接、战斗运镜、环境反馈和特效轨迹。
- 不负责：改写剧情、改变胜负、增加人物或台词、替换武器、重新设计人物外观、输出整集分镜。
- 由 `storyboard-director` 调用时，只返回动作方案，由分镜技能负责镜号、台词、时长、站位连续性和最终包装。
- 独立使用时，按用户指定平台和时长输出；未指定时按 Seedance 类模型的 15 秒单元组织。

## 输入优先级

1. 用户本次明确要求。
2. 当前项目剧本中的战斗节点和不可改结果。
3. 当前项目数据库、人设和分镜缓存。
4. 通用动作与镜头原则。

若输入之间存在会改变胜负、角色能力或关键伤势的严重冲突，暂停并询问用户。其他缺失信息采用最保守方案，不擅自补充招式名、超能力或武器。

## 战斗调用单

由分镜技能调用时，只接收以下最小信息：

```text
剧情节点与不可改结果：
目标平台、画幅与持续时间：
角色A：战斗风格、惯用手、武器、能力源点
角色B：战斗风格、惯用手、武器、能力源点
初始站位、朝向与距离：
场地结构与可交互物：
胜负、伤势与场景破坏结果：
禁改项与生成风险：
```

不得要求调用方重复提供整集剧本或全部数据库。

## 内部工作流

1. 锁定剧情边界：确认开战原因、当前局势、必须发生的转折和最终结果。
2. 锁定角色技法：只使用来源资料明确存在的武学、身体能力、武器和超能力；未指定招式名时使用可见动作描述。
3. 建立空间图谱：记录左右/前后/高低、朝向、距离、障碍、出口和相机轴线。
4. 拆分动作链：从起势、进攻、防守、反击、位移、受力、卸力和结果中选择必要节点。
5. 绑定因果：每次攻击写清发力点、运动方向、接触点、防守方式和可见结果。
6. 设计镜头：每个镜头只保留一个核心运镜，并让景别服务动作尺度。
7. 绑定特效：只有来源设定包含能力或衍生效果时才添加，写清源点、形态、轨迹、衰减和终点。
8. 检查连续性：惯用手、武器持握、伤势、站位、轴线、场景破坏和剩余距离必须前后一致。

## 动作设计规则

### 单一因果

一个动作节点只表达一个主因果链：攻击发起 -> 防守/接触 -> 受力结果。无关人物反应另拆节点。

### 攻防转换

- 连续攻击必须有防守反馈，不能让双方各自表演。
- 格挡、闪避、卸力和反击必须从上一动作留下的肢体位置自然发生。
- 摔投与擒拿必须写清抓握点、重心转移、支撑脚和落地方向，避免复杂肢体缠绕一笔带过。
- 追逐必须写清双方路径、速度差、障碍物和距离变化。

### 力学传导

- 写清力量从脚步、髋部、躯干、肩肘、手腕或武器何处发起。
- 写清运动方向、接触位置、阻力、反作用力和卸力方式。
- 环境反馈必须符合材质；金属、木材、玻璃、泥土和水面不能使用相同破坏表现。
- 关键命中后用短节点确认结果，例如重心后移、滑退距离、武器震颤、裂纹或尘土轨迹。

### 能力与特效

- 没有超能力设定时，只使用人体动作、武器运动和环境反馈。
- 有能力设定时，持续锁定能力源点、颜色、材质、范围和消耗表现。
- 动作与衍生效果在同一因果节点绑定，避免只挥武器却遗漏已设定的投射物。
- 远程效果写明方向、速度、宽度变化、衰减和终点，不默认无限扩散。
- 爆炸、液体、尘土、碎屑和能量沿明确三维轨迹运动，避免平面贴图感。
- 复原、异化、合体和极速位移使用可见中间态，避免瞬间溶解或肢体跳变。

## 镜头规则

- 小幅拳掌、格挡、抓握和表情反馈优先中近景或近景。
- 大跨度位移、腾空、摔投和场景破坏优先中景或全景。
- 接触瞬间可以使用短促推镜、甩镜或升格，但同一镜头只保留一种核心运动。
- 保持 180 度轴线；确需换轴时，用中性过渡镜头或明确跨轴运动完成。
- 近景转远景通常经过中景；紧急反差剪辑只有在动作方向仍可读时使用。
- 画幅服从当前项目；未指定时使用 16:9 横屏。

## 输出格式

由 `storyboard-director` 调用时输出：

```markdown
## 战斗动作方案

- 剧情边界：
- 初始站位：
- 轴线与运动方向：

### 起势
- [可见动作、力学与镜头建议]

### 攻防动作链
1. [攻击 -> 防守/接触 -> 受力结果]
2. [攻击 -> 防守/接触 -> 受力结果]

### 转折
- [破绽、空间变化或能力变化]

### 终结与结果
- [终结动作与不可改结果]

### 连续性锁定
- 惯用手/武器：
- 能力源点/颜色：
- 伤势/场景破坏：
- 结束站位与距离：
```

独立使用时，在上述结构前补充目标平台、画幅和总时长，并为每个节点给出连续时间段；总时长不得超过目标平台限制。

## 自查

- 是否严格保持原剧情、人物、台词边界、胜负和伤势结果？
- 是否只使用当前项目已设定的技法、武器、能力和特效？
- 每个动作是否有明确发力、方向、接触、防守和结果？
- 惯用手、持握、站位、轴线和距离是否连续？
- 是否避免无依据的剑气、重力场、爆衣、肢体膨胀或固定角色特效？
- 是否把复杂缠绕、多人混战和极速旋转拆成模型可生成的动作节点？
- 是否适配目标时长、平台和画幅？

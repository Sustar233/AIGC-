# 角色提示词模板

仅在需要把剧本元素交给人设技能时使用本模板。

## 必含要素

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名/代号 | 当前项目中的称呼 | 角色A |
| 种族/身份 | 物种、职业、阵营或剧情身份 | 人类，边境调查员 |
| 外貌特征 | 年龄感、脸型、五官、发型、发色、肤色、体型 | 黑色短发、灰绿色眼睛、高挑精瘦 |
| 服装与材质 | 符合时代、地域、职业和剧情状态的造型 | 深灰功能夹克、磨砂金属护腕 |
| 表情气质 | 可转化为表演的气质关键词 | 冷静、警觉、克制 |
| 武器/能力 | 惯用手、持握方式、能力源点、颜色与尺度 | 左手短杖，蓝白能量从杖首释放 |
| 构图模式 | 三视图、全身图、表情组或用户指定形式 | 三视图角色设定图 |

## 输出格式

```text
【角色名】- [构图模式]

版本A（精简版）：
[只包含剧本与数据库明确写出的识别特征]

版本B（完整版）：
[在不冲突的前提下补充材质、光影、姿态和3D动漫渲染信息]

版本C（可选风格版）：
[仅在需要平台或美术方向变体时输出]
```

## 注意事项

- 保持当前项目的人物、时代和美术规则，不套用其他项目设定。
- 主要角色默认三视图或标准全身设定图，背景默认纯白；用户指定其他用途时调整。
- 只有用户要求更新数据库时才附加 JSON，并严格沿用当前项目结构。
- 默认不输出 negative prompt。

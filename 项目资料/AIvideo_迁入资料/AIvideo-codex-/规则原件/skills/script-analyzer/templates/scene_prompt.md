# 场景提示词模板

仅在场景信息影响当前人设、分镜或连续性时使用。

## 必含要素

| 字段 | 说明 | 示例 |
|------|------|------|
| 场景名称 | 当前项目中的稳定命名 | 北区悬浮车站 |
| 空间类型 | 室内/室外、城市/荒野、开放/封闭 | 室外高架交通节点 |
| 空间结构 | 出入口、层级、通道、遮挡与可站立区域 | 双层站台，西侧楼梯，中央候车区 |
| 材质与年代 | 建筑语言、主材质、磨损状态 | 浅灰复合金属与半透明玻璃 |
| 时间与光源 | 时段、主光方向、色温、天气 | 阴天午后，顶部漫射冷光 |
| 关键物件 | 影响动作、站位或剧情的可交互物 | 闸机、长椅、悬浮信息牌 |
| 尺度参照 | 人、门、载具或建筑层高 | 站台宽12米，人物为尺度参照 |
| 构图模式 | 全景、俯视图、布局图或用户指定形式 | 16:9空间建立全景 |

## 输出格式

```text
【场景名】- [构图模式]

版本A（结构锁定版）：
[强调空间结构、尺度、材质和关键物件]

版本B（气氛完整版）：
[在结构不变的前提下补充3D动漫光影、天气和色彩]
```

## 注意事项

- 场景必须符合当前项目题材和美术方向。
- 未明确的时间、天气或光影可以合理推断，但要标注为推断。
- 只有用户要求更新数据库时才附加 JSON，并严格沿用当前项目结构。
- 默认不输出 negative prompt。

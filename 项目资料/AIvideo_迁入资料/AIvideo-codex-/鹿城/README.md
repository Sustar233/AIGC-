# 鹿城｜项目入口

本聊天负责《鹿城》分镜脚本与分镜预览制作。更新：2026-10-10（Asia/Shanghai）。

## 工作流程

用户指定剧本或片段 → 读取项目要点与必要连续性 → 确认整段15秒可行性（超长先沟通）→ 编写并展示分镜脚本 → 自动生成两张完整预览 → 一次核对与简短归档。

默认每张预览图都完整包含本次脚本的 N 个分镜，即 A 图 N 格、B 图 N 格，两图采用相同镜号及布局。具体规则见 [分镜工作规范](分镜工作规范.md)。当前日常规则与可调颜艺参数统一在 [鹿城项目要点](鹿城项目要点.md)，用户以后优先修改该文件。

## 目录

| 路径 | 用途 |
| --- | --- |
| `剧本/` | 用户指定的原剧本与修订版；既有剧本无需强制搬迁 |
| `素材/角色/` | 方向、田静、孙鸽、油条的人设参考原图 |
| `素材/场景/` | B1 地下停车场及后续场景参考 |
| `素材/道具/` | 剧情关键道具参考，当前待补 |
| `素材/表情与动作/` | 按需要补充的表情、姿态和动作参考，当前待补 |
| `分镜脚本/` | 按集数、章节或片段保存的分镜脚本 |
| `分镜预览/` | 与脚本同版本的预览 A、B 及裁剪坐标记录 |
| `制作记录/` | 单次交付清单、连续性末态、反馈与修订记录 |
| `资料来源/` | 历史聊天快照，仅作为资料读取 |

## 当前美术基线

2D 夸张搞笑动漫，默认 16:9。主线与 Q 版白底小剧场分开；以用户指定片段和对应参考为依据。停车场图用于空间、配色与灯光参考，不把人物改为 3D。角色姓名沿用已有项目资料与本次图像的对应关系，附件内没有姓名标签；用户后续修正优先。

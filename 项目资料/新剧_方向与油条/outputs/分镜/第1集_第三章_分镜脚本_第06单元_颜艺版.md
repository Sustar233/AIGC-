# 第一集·第三章·第6单元·颜艺版

画面风格：2D夸张搞笑动漫，16:9横屏。清晰二维线稿、平涂色块、简洁阴影。采用放得开的搞笑漫表演：允许颜艺崩脸、巨口白眼、五官错位、头身比例突变、Q版切换、橡皮式挤压拉伸、漫画冲击帧、抽象气氛背景与骤停定格。按笑点选择具体手法，以预备、爆发、停顿和突变形成节奏；夸张幅度可突破正常人体比例，保留发型、服装等角色识别锚点，表演结束可瞬间弹回常态。漫画符号与气氛背景属于表现层，实际场景位置及剧情结果保持连续。
预计时长：约12—14秒。按约35字对白、站位展示及吃瓜动作估算，尚未配音实测；镜号0控制在1—2秒，其余不刻意拖长。

场景：B1地下停车场，正常人设的现实对话。
出场人物：方向、田静、油条。
画面综述：从Q版卧室直接切回现实站位全景。田静在画右，肩背靠着关闭的驾驶侧前门；方向在画面中左、站在田静前方通道面对她，油条在方向身体右手侧，投影为画左偏近，保持身高差与原有间距。机位始终在对话轴同侧，正反打靠近轴线。田静戴粉帽、黑口罩、棕马尾、米色短外套、黑裙，肩包保留，双手空着，购物袋玩偶在车里。方向右手手机先在腹前，镜号1收回右侧裤袋，镜号3才揭示两人各抱半瓜。
车辆锁定：深海军蓝金属漆四门三厢轿车，车头朝左、驾驶侧朝通道，所有车门关闭，深色车窗、细银色窗框及银色多辐轮毂保持；冷光只产生蓝灰高光，不变黑车或其他车型。

镜号 0
镜头语言：三人站位全景，平视固定镜头，1—2秒内完成展示。
画面描述：田静在画右靠着关闭的深蓝车门，双脚落地、双手空着；方向和油条站在她面前的通道，三人完整身形、脚点、间距与关门状态同时清楚可见。方向灰黑挑染发、米色盘扣外套，油条紫色双尖帽、金色短马尾、深灰紫毛衣，全部保持正常人设比例。方向下巴略抬、视线暂在上方，油条抬眼看他一下后看向田静；田静安静望着方向。镜头稳定落幅，用于交代位置，不演对白、不插颜艺变脸。停车场上方没有悬浮小剧场。
台词：无。
音效：车库通风底噪自然恢复。

镜号 1
镜头语言：方向单人正面近景，取头顶至腰部，固定镜头，完整保留收手机动作。
画面描述：方向把略抬的视线收回镜头右侧画外的田静，左手放下，右手将腹前手机收回右侧裤袋。他一只眼睁圆、另一只眼半眯，两眉一高一低，嘴角向一边微扯，定在“这理由说得通吗”的大小眼疑问脸上念完整句。只保留这一套表情，不突然转惊恐；背景仅有车库结构，无其他人物局部或倒影。
台词：方向（疑惑确认）：【他骗你就是为了要赔款？】
音效：一声轻微衣料摩擦，底噪连续。

镜号 2
镜头语言：田静单人正面面部特写，固定镜头，帽檐至下巴，双眼清楚可见。
画面描述：田静看着镜头左侧画外的方向，上眼睑向下压、下眼睑微抬，眉心紧锁，棕色瞳孔凝住，整张脸停在“咬住怒气”的尖锐眼神上。重落“卖掉”时头略向前顶一下，仍保持同一套眉眼，不切换圆眼、哭脸或第二种颜艺。黑口罩全程遮住口鼻，不透出嘴型；背景只留深蓝车门和环境高光。
台词：田静（压着怒气，重落“卖掉”）：【他的真实目的，只是把我骗去国外卖掉！！】
音效：环境声稍压低，尾音保留短促车库回声，不加滑稽音效。

镜号 3
镜头语言：方向、油条双人正面镜，固定机位，方向画右、油条画左，双方头脸、手与半个西瓜均完整可读。
画面描述：直接从田静的特写切来，两人已经各用左臂托着半个西瓜，红瓤朝上，右手握小勺，方向手机仍在裤袋里。方向眉毛内收、眼睛半眯，像认真分析案情；油条圆眼专注，捧瓜也一本正经。两人看着画外田静，保持这套认真吃瓜脸，语尾上扬地同时问“卖人？”，只做正常发声嘴型，不插白眼惊跳或独立震惊停顿。话音落下，方向低头挖一勺，油条侧目跟一下他的动作再挖一勺，两人各吃一口，视线回到田静身上继续听。整个镜头连贯完成发问与吃瓜，以严肃神情、离谱内容和熟练挖瓜形成反差；不含着瓜念台词，不喷汁、不夸张鼓腮。
台词：方向、油条（认真地同时确认，尾音上扬）：【卖人？】
音效：对白后接两声轻挖瓜声，咀嚼轻带过，不加惊跳音或罐头笑声。

其他要求：
- 镜号0为独立站位建立镜，不超过2秒；正文只用镜号1—3讲完对白，无额外震惊镜或吃瓜尾镜。
- 镜号1大小眼疑问、镜号2咬住怒气、镜号3认真吃瓜，每镜一套表情。现实人物不Q版化，身体左右、相对间距与身高差不变。
- 单人镜禁止其他角色及其局部、影子和倒影；镜号3只出现方向与油条，田静在画外。车门始终关闭。
- 西瓜依剧本以喜剧省略方式在镜号3揭示，不加变物光效、购物或切瓜过程。手机已收起，每人左臂托瓜、右手持勺，手部动作不冲突。无对白字幕。

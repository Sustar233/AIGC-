# 第1集《尤卡降临》分镜脚本｜方舟扇形三连击与成交（单元3）

- 剧本范围：原剧本“野猪怒吼道：【打他！】”至赛几回应“好！我要了！”
- 制作模式：紧凑成片版（多人战斗优化，修订版）
- 构图限制：所有镜头只使用中景、中近景或近景，镜内仅保留当前动作需要的角色；背景裁切在食堂外墙玻璃门的室内入口一侧，门外明确为校园室外，不展示餐桌区。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第3单元 / 方舟、野猪A、野猪B、野猪C、赛几]
第 3 单元：扇形三连击与成交
分镜类型：战斗分镜优化
场景：王子学院食堂外墙玻璃门内侧入口通道（门外为校园室外）
时间：日/内
出场人物：方舟、野猪A、野猪B、野猪C、赛几
时长：15 秒
画面综述：
食堂外墙上的透明玻璃门是室内外唯一分界，所有角色均位于门槛内侧；方舟站在玻璃门内侧不远处，一手持外卖袋，另一只手靠近腰间烧烤铲。三头同模黑野猪从食堂内部方向逼近，在方舟前方形成左、中、右三点半包围，赛几留在安全画外。参考分镜采用三个构图节点：方舟居中被围、固定正面机位完成扇形三连击、三头猪横向排开落地。方舟按A、B、C顺序，以向左外拍、中央斜上拍、向右反拍连续击飞三者，飞行方向均远离玻璃门。

镜号 1
镜头语言：中近景 / 从三头猪人肩后正面拍向方舟 / 固定机位 / 方舟居中，野猪A、B、C的头肩分别压在左下、中下、右下前景 / 对应参考图一，用于包围压迫与拔铲前蓄势
画面描述：【方舟固定在食堂外墙玻璃门内侧，镜头只保留玻璃门上半部；门外是校园室外自然日光，不拍门口地面】野猪A在左前景怒吼，B、C从中、右前景同时压近，但尚未进入接触距离。方舟被三者围在画面中心，神情平静，持外卖袋的手不动，另一只手已经握住腰间烧烤铲把手；画面四周出现向中心聚拢的二维压迫线。
台词：野猪A【恼怒、爆发】：“打他！”
音效：野猪A短促怒吼，三头猪人加重的鼻息声。

镜号 2
镜头语言：中景 / 延续上一镜的正面中心机位 / 固定机位 / 方舟全身保持在画面中心，三头猪人与三处接触闪光向左、中、右展开 / 对应参考图二，用于一次连续动作完成扇形三连击
画面描述：【方舟双脚保持中心支撑，持外卖袋的手始终稳定；烧烤铲只有一个本体，三头猪按A、B、C顺序接触，禁止同时受击】野猪A从左前方先扑近，方舟贴腰抽铲，借拔铲动作向左外侧短拍A的面颊，A沿左上方弧线飞向食堂内部。铲面不停，顺势绕回胸前；野猪B从中央进入，方舟屈膝下沉后斜向上弹拍，B沿中央高弧线后翻飞出。方舟再借上挑余势旋腕回铲，反手向右外侧拍中刚进入距离的野猪C，C沿右上方弧线飞出。三次接触依次爆开左、中、右三簇扁平星形闪光，铲面只留下连接三击的平面弧形残影；A、B、C形成向食堂内部展开的扇形飞行轨迹，全部远离玻璃门和赛几。三者仅留下相同浅红方形铲印，五官、脸型和身体比例不变。
台词：无。
音效：烧烤铲利落抽出声，连续递进的三声“啪、啪、啪”，三道分别朝左、中、右散开的短促破风声。

镜号 3
镜头语言：中景 / 食堂入口通道贴地正拍 / 固定机位 / 野猪A、B、C横向排在左、中、右三个落点 / 对应参考图三，用于三名击飞结果确认与赛几OS
画面描述：【镜头朝食堂内部落地区域，不拍玻璃门、餐桌或其他食客】野猪A先落在左侧，野猪B随后落在中央，野猪C最后落在右侧，三次落地各出现一簇扁平尘形冲击线。三头猪均横躺在地，头部与上半身完整可见、互不遮挡、互不合并；三者保持同模同脸和相同浅红方形铲印。赛几固定在镜头外观看。
台词：赛几（内心独白）【惊讶、佩服】：“这家伙！好厉害！”
音效：三次错开的轻量落地声，食堂入口处环境音。

镜号 4
镜头语言：中近景 / 平视双人侧拍 / 固定机位 / 方舟位于左侧，赛几位于右侧，背景保留食堂外墙玻璃门及门外室外日光 / 用于方舟报价
画面描述：【方舟与赛几都在玻璃门内侧的食堂入口；透过透明门可见室外地面与自然日光，门外没有天花板、内墙、走廊或室内家具】方舟收住烧烤铲，转头看向赛几，眼角轻抬并狡黠眨眼；外卖袋仍由另一只手持在胸侧。他朝赛几示意袋子，开口报价。三名倒地猪人在镜头下方裁切外。
台词：方舟【狡黠、轻松】：“同学，这烧烤你要吗？给你打折”
音效：塑料外卖袋轻微窸窣声，方舟轻松的说话声。

镜号 5
镜头语言：近景 / 平视反打 / 固定机位 / 焦点锁定赛几的坏笑与眨眼，方舟肩部保留在左侧前景边缘 / 用于成交落点
画面描述：【赛几保持在右侧原位，方舟位于左侧近景裁切边缘】赛几看向方舟手里的外卖袋，一侧嘴角扬起，坏笑着眨眼回应。方舟没有递出外卖袋，交接动作留待后续镜头。
台词：赛几【坏笑、爽快】：“好！我要了！”
音效：赛几轻快的回应声，食堂入口处环境音恢复。

其他要求：
·  镜头时长估算：镜号1 0-1秒；镜号2 1-7秒；镜号3 7-9秒；镜号4 9-13秒；镜号5 13-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识，三次“啪”只作为声音出现。
·  不加字幕。
·  所有镜头限定为中景、中近景或近景，镜内只出现当前动作明确需要的角色；玻璃门固定嵌在食堂外墙，角色全部位于门内，门槛外直接连接校园室外地面并有自然日光，禁止把门外生成成带天花板、内墙、走廊、餐桌或家具的第二室内空间。
·  三次拍击严格按野猪A、B、C顺序完成，镜号2采用参考图式正面固定机位，三条纯二维轨迹分别向左、中央、右侧扇形展开且全部远离玻璃门；镜号3固定为A左、B中、C右三名横躺猪人，禁止漏掉、合并、复制替换或只生成两名。
·  三头猪人全程同模同脸、同体型和同外观，均只比赛几高约半个头；烧烤铲始终只有一个本体，可出现连接三击的平面弧形残影、速度线和扁平撞击闪光，禁止复制出三把铲、猪人变脸、身体拉伸或三维立体特效。
·  方舟的外卖袋不换手、不掉落，烧烤铲由另一只手完成三连击并保持在手中；赛几的内心独白不引发旁人反应，本单元完整覆盖原剧本第69-74行并停在成交回应之后。

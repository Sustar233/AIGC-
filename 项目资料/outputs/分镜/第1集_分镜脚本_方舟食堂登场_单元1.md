# 第1集《尤卡降临》分镜脚本｜方舟食堂登场（单元1）

- 剧本范围：原剧本“喂！猪怎么跑进食堂了？”至“这外卖你们买单吗？”
- 制作模式：多人场景精细版
- 台词归属：结合原剧本上下文与门口登场要求，首句由方舟说出。
- 站位标识：野猪A、野猪B、野猪C仅用于连续站位和台词归属；三头野猪的角色模型、脸、体型、毛色与服装完全相同，不设计个体外形差异。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第1单元 / 方舟、野猪A、野猪B、野猪C、赛几]
第 1 单元：玻璃门来客
分镜类型：多人场景优化（精细版）
场景：王子学院食堂靠室外玻璃门、入口通道与普通学生桌椅区
时间：日/内
出场人物：方舟、野猪A、野猪B、野猪C、赛几
时长：15 秒
画面综述：
镜头从食堂室内朝向靠近室外的玻璃门。方舟从玻璃门进入，一手提着一次性塑料外卖袋，方形烧烤铲别在腰部，随后缓缓沿入口通道向室内走近，在画面左侧停下并面向右侧冲突区。野猪A位于右侧前方，保持把赛几提离地面少许的姿态；野猪B、野猪C在其右后方前后错落。三头野猪采用完全相同的角色模型、五官结构、脸型、獠牙、耳形、鼻形、体型、毛色、校服与头顶标识，只能通过A、B、C的固定站位区分，所有镜头禁止变脸、串脸、换脸或外观漂移。三头野猪与赛几体型接近，仅比赛几高约半个头、躯干略宽，禁止巨型化，也禁止把赛几缩成玩偶比例。方舟先出声调侃，三头野猪转头恼怒，野猪A质问，方舟举起外卖袋淡定询问谁来买单。相机始终位于对峙轴线同一侧，方舟保持在左，三头野猪与赛几保持在右。猪王子、食堂阿姨及其他食客保留在既有画外位置，不入镜、不离场。

镜号 1
镜头语言：全景 / 室内朝向玻璃门的略低机位 / 低机位跟拍 / 玻璃门位于左后方，焦点锁定方舟的行走、外卖袋与腰间烧烤铲 / 用于主角进门与帅气登场
画面描述：【方舟从靠近室外的玻璃门进入食堂，沿入口通道缓缓向室内前行；同一只手始终提着一次性塑料外卖袋，方形烧烤铲始终别在腰部，不换手、不掉落】方舟跨过玻璃门门口后以均匀缓慢的步幅向室内走近，外卖袋随步伐轻轻摆动，腰间烧烤铲保持稳定。他抬眼望向室内冲突区，玻璃门始终留在身后左侧，形成清晰的二维少儿动画入场路线。
台词：无。
音效：玻璃门轻响，方舟缓慢脚步声，塑料外卖袋轻微窸窣声，食堂室内低声环境音。

镜号 2
镜头语言：中全景 / 略低机位 / 固定机位 / 方舟占左侧三分线，野猪A与赛几占右侧前方，野猪B、野猪C在右后方错落排开 / 用于建立五名角色关系与方舟第一句台词
画面描述：【以相机中轴线为基准，锁定方舟在左侧室内通道、野猪A与赛几在右侧前方、野猪B在右后方靠近中轴、野猪C在更右后方；方舟已停止行走，五名角色不换位、不叠人】方舟停下脚步，身体正对三头野猪，提袋手自然垂在身侧，烧烤铲仍别在腰部。野猪A保持把赛几提离地面少许，赛几身体为正常角色尺度；野猪B和野猪C仍朝向原冲突区。方舟抬起下巴，高声开口。
台词：方舟【高声、短促挑衅】：“喂！猪怎么跑进食堂了？”
音效：方舟声音在食堂内产生轻微回响，背景食堂声自然降低。

镜号 3
镜头语言：中近景 / 平视侧拍 / 固定机位 / 焦点锁定右后方的野猪B与野猪C，野猪A仅保留前景边缘轮廓 / 用于拆分两头无台词野猪的恼怒反应
画面描述：【野猪B与野猪C始终使用完全相同的固定角色模型和固定五官，野猪B位于右后方靠近中轴，野猪C位于更右后方；两者只转身，不向前移动】野猪B与野猪C同时转头看向画面左侧的方舟，眉头压低，鼻翼张开。两张脸只发生相同的表情变化，脸型、五官位置、獠牙、耳朵、鼻子、毛色与体型全程不变，禁止变脸或生成任何个体差异。
台词：无。
音效：短促转身带起的衣料摩擦声，两声压低的鼻息。

镜号 4
镜头语言：中近景 / 略低机位 / 缓慢前推 / 焦点锁定野猪A的固定面部与赛几正常比例的身体 / 用于野猪A主反应与质问
画面描述：【野猪A与野猪B、野猪C使用完全相同的固定角色模型和固定五官；野猪A位于右侧前方，保持把赛几提离地面少许，三头野猪均只比赛几高约半个头、躯干略宽】野猪A转头盯向左侧方舟，眉头下压，鼻息加重；他保持原有发力姿态，赛几双脚只离地少许，赛几身体不缩小、不变成玩偶比例。野猪A张口短促质问，发言过程中脸型、鼻形、獠牙与耳形保持不变。
台词：野猪A【恼怒、短促质问】：“谁？你说什么？”
音效：野猪A加重的鼻息声，台词后的短促室内回响。

镜号 5
镜头语言：中近景 / 略低机位 / 缓慢前推 / 焦点锁定方舟的面部、外卖袋与腰间烧烤铲，野猪A肩部保留在右侧前景边缘 / 用于方舟完整台词与喜剧落点
画面描述：【方舟固定站在画面左侧室内通道，身体朝向右侧野猪群；同一只手始终持有外卖袋，方形烧烤铲始终别在腰部；三头野猪与赛几保持右侧既定站位】方舟把一次性塑料外卖袋抬到胸侧，视线从袋子平稳移到野猪A脸上，眉眼保持放松，嘴形清楚对应整句台词。说到问句末尾时，他的提袋手停住，身体与腰间烧烤铲均保持稳定。
台词：方舟【淡定、正常偏慢】：“我的客户昏了过去，这外卖你们买单吗？”
音效：塑料外卖袋随抬手发出轻微窸窣声，食堂环境音持续。

其他要求：
·  镜头时长估算：镜号1 0-3秒；镜号2 3-5秒；镜号3 5-6秒；镜号4 6-8秒；镜号5 8-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识。
·  不加字幕。
·  本单元固定角色集合为 5 名：方舟、野猪A、野猪B、野猪C、赛几；近景未入画角色均为摄影机裁切，不得被生成成离场或消失。
·  三头野猪必须同模、同脸、同体型、同毛色、同校服、同头顶标识，前后镜头五官比例和轮廓完全一致；禁止变脸、串脸、换脸、脸型漂移、颜色漂移和体型漂移，只允许表情与头部朝向按剧情变化。
·  三头野猪与赛几保持接近体型，野猪仅高约半个头、躯干略宽；禁止野猪巨型化，禁止缩小赛几，禁止出现“成年人抓玩偶”式比例。
·  方舟必须从靠近室外的玻璃门进入，并在开篇缓缓向室内行走；进入后玻璃门始终位于方舟身后左侧，不得变成木门、金属门或室内隔断门。
·  全程锁定方舟在左、三头野猪与赛几在右的对峙轴线，不越轴、不镜像翻转。
·  方舟的外卖袋由同一只手连续持有，腰间烧烤铲不得提前取下；野猪A不得提前放下赛几，三头野猪不得提前上前或发动攻击。
·  台词栏只保留角色、必要情绪和原始台词，不写字速数值、剪辑术语或时长参数。
·  画面严格保持二维线稿与平面色块，不出现三维建模体块、写实CG材质、体积光或游戏引擎渲染质感。

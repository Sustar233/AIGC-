# 第1集《尤卡降临》分镜脚本｜外卖骗局（单元4）

- 剧本范围：原剧本第76-80行“看着方舟骑电驴离开”至赛几“啊！？那个骗子！”
- 制作模式：紧凑成片版（双人对白优化）
- 构图限制：全程仅使用中景、中近景或近景；第一镜由食堂室内透过关闭的外墙玻璃门观察室外，但画幅保持在人物腰部以上，不拍门口地面；赛几随后立即向食堂内部走，三头倒地猪人始终固定在其身后的门口画外区域。猪王子只在食堂内部出现，并与三名黑色尤卡野猪人严格区分。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第4单元 / 赛几、猪王子、方舟]
第 4 单元：外卖骗局
分镜类型：普通对白
场景：王子学院食堂外墙玻璃门内侧至食堂内部通道
时间：日/内
出场人物：赛几、猪王子、方舟
时长：15 秒
画面综述：
外墙玻璃门保持完全关闭，门内是食堂入口，门外直接连接校园室外地面。赛几手持塑料外卖袋，在门内看见方舟骑电驴离开后立即转身沿通道向食堂内部走；三头倒地猪人仍在玻璃门附近，始终留在赛几身后的画外区域。猪王子是赛几的本地学生同伴，不是黑色尤卡野猪人；他位于食堂内部较深处，从地面爬起后与迎面走来的赛几相遇，二人才开始对话。

镜号 1
镜头语言：中近景 / 食堂室内过赛几肩侧拍向关闭的玻璃门上半部 / 固定机位 / 前景锁定赛几与塑料袋，门外局部锁定正在驶离的方舟 / 用于离开、内心评价与转身起步
画面描述：【画幅保持在赛几腰部以上，玻璃门已经关闭；门外明确是有自然日光的校园室外，不拍门槛和门口地面】赛几隔着玻璃看见方舟骑电驴驶出局部画幅，低头看一眼手中的塑料外卖袋，随即背对玻璃门转身，开始朝食堂内部走。不表现开关门过程，不展示室外大全景。
台词：赛几（内心独白）【感叹、带着佩服】：“真是胆大的家伙呢！”
音效：隔着玻璃传来的电驴渐远声，塑料袋轻微窸窣声。

镜号 2
镜头语言：中景 / 食堂内部平视侧拍 / 轻微跟移 / 赛几沿通道由入口方向走向食堂内部 / 用于明确离开门口的空间位移
画面描述：【镜头朝向食堂内部，玻璃门、门口地面和三头倒地猪人全部位于赛几身后的镜头外】赛几提着塑料袋连续向里走过数步，门口不再进入后续构图；他听见前方传来动静，脚步稍微放慢。
台词：无。
音效：赛几由远及近的脚步声，塑料袋随步伐轻晃的窸窣声。

镜号 3
镜头语言：中景 / 食堂内部平视侧拍 / 固定机位 / 猪王子在右侧从地面爬起，赛几从左侧迎面走来 / 用于区分角色并完成相遇
画面描述：【猪王子固定使用王子学院本地学生同伴的独立角色造型，不是黑色尤卡野猪人；禁止黑色野猪外观、獠牙、尤卡校服、头顶标识、方形铲印或野猪A/B/C的同款脸】猪王子在食堂内部的通道地面用手撑起身体，刚站稳便一手捂住挨打的脸。赛几从入口方向走来，正好与他迎面遇上并停步；猪王子的目光落到塑料袋上。
台词：猪王子【刚醒、饿得迷糊】：“欸，外卖到了啊！好饿哦！”
音效：手掌撑地与衣料摩擦声，猪王子起身时的轻微吃痛声。

镜号 4
镜头语言：中近景 / 室内双人侧拍 / 固定机位 / 赛几在左、猪王子在右，焦点偏向赛几的无语表情 / 用于赛几请客
画面描述：赛几眼皮压低，嘴角无奈地向一侧撇开，抬了抬手中的塑料袋向猪王子示意；猪王子站在原位捂脸，期待地望着袋子。
台词：赛几【无语、认栽】：“哎，算我请你吧！”
音效：塑料袋被轻轻提起的窸窣声。

镜号 5
镜头语言：中近景 / 平视反打 / 固定机位 / 猪王子占右侧主体，赛几肩部留在左侧前景 / 用于已付款信息反转
画面描述：猪王子先愣一下，随即把捂脸的手放低少许，理直气壮地看向赛几；赛几保持提袋姿势，身体瞬间僵住。
台词：猪王子【理直气壮、带点委屈】：“什么嘛！我已经付钱了！”
音效：食堂室内轻微环境音短暂收低。

镜号 6
镜头语言：近景 / 室内平视正拍 / 快速小幅前推 / 焦点锁定赛几从僵住到炸毛的表情，猪王子只保留在画面边缘 / 用于被骗笑点落幅
画面描述：赛几先低头看向手中的塑料袋，眼睛骤然睁大；下一瞬头顶毛发炸起，猛地回头望向身后很远的玻璃门方向，但镜头不跟过去、不重新拍门口。猪王子在边缘困惑地眨眼，没有离开原位。
台词：赛几【炸毛、震惊】：“啊！？那个骗子！”
音效：短促的二维弹跳音，塑料袋被攥紧的窸窣声。

其他要求：
·  镜头时长估算：镜号1 0-3秒；镜号2 3-5秒；镜号3 5-8秒；镜号4 8-10秒；镜号5 10-13秒；镜号6 13-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识。
·  不加字幕。
·  玻璃门从第一帧到单元结束始终完全关闭；第一镜只拍玻璃门上半部，门外只允许出现校园室外自然日光与局部离开的方舟，禁止出现门口地面、第二个室内空间或开关门动作；赛几随后连续走向食堂内部，镜号2起玻璃门及三头倒地野猪固定在其身后的画外区域。
·  除第一镜门外局部出现方舟外，其余镜头只允许赛几与猪王子出镜；猪王子必须在食堂内部爬起并使用独立角色造型，禁止生成成黑色尤卡野猪人、野猪A/B/C、第四头同模野猪或带方形铲印的倒地野猪。
·  赛几全程位于室内并连续持有同一个一次性塑料外卖袋；与猪王子相遇后的对话轴线固定为赛几在左、猪王子在右，二人均不得瞬移回玻璃门前。
·  不展示方舟的烧烤铲及腰部细节，不新增外卖袋交接、食物展示、敲门声或门外来人；赛几的内心独白只有本人能听见。

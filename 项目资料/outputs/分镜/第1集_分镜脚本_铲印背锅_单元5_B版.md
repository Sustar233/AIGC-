# 第1集《尤卡降临》分镜脚本｜方形证据（单元5·重制B版）

- 剧本范围：原剧本第81-88行“咚咚咚”至赛几“外卖佬！你给我回来！”
- 制作模式：紧凑成片版（多人场景优化·证据喜剧版）
- 构图限制：全程只使用中景、中近景、近景或局部特写，不使用食堂及室外大全景；开门前后采用同一固定低机位，画面下层锁定三头横躺不动的黑野猪，画面上层锁定五名完全同模的鸟人由室外进入。进入玻璃门的只能是鸟人，三头猪人不得站起、行走或加入进门队伍。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

画面综述：
赛几已从门口走到食堂内部通道，手持塑料外卖袋。野猪A、B、C保持完全相同的黑野猪模型，分别横躺在玻璃门内侧地面的左、中、右三个固定位置，三者从开场到结束均不起身、不移动。关闭的玻璃门外是校园室外，五名鸟人使用完全相同的角色模型，以A居前、B至E错落在后敲门，随后绕过倒地猪人进入。赛几欲走时被B抓住，领队A以野猪A的方形铲印指证，赛几发现口袋里的烧烤铲后暴怒。

镜号 1
镜头语言：中景 / 食堂室内贴近地面的正面机位 / 固定机位 / 下层锁定横躺的野猪A、B、C，上层透过关闭玻璃门锁定门外五名鸟人 / 用于同时建立倒地状态、室内外边界与人数
画面描述：【门内地面与门外校园由关闭的玻璃门清楚分隔】野猪A、B、C分别横躺在门内地面左、中、右三个互不重叠的位置，身体保持水平并完全静止，三者之间留有通行空隙。门外领队A抬手敲门，鸟人B、C位于第二层，D、E位于第三层；五名鸟人均使用同一模型，五个鸟头和五副肩部轮廓清楚可辨。赛几在食堂内部画外听见声音。
台词：无。
音效：三下清楚的敲门声“咚、咚、咚”。

镜号 2
镜头语言：中景 / 延续上一镜的食堂室内低机位 / 固定机位 / 下层三头猪人保持横躺，上层五名同模鸟人沿空隙依次跨过门槛 / 用于明确只有鸟人进入
画面描述：【机位、猪人位置与上一镜完全不变】领队A推开玻璃门，从三头倒地猪人之间的通行空隙跨入食堂；B、C、D、E保持鸟人外形，随后依次绕开猪人进入门内。整个过程中野猪A、B、C始终横躺原地，不抬头、不站立、不迈步，也不随鸟人穿过门槛。五名同模鸟人全部进入后，领队A朝食堂内部厉声发问。
台词：鸟人领队A【严厉、护短】：“是谁？谁袭击我可爱的学生！”
音效：玻璃门开启声，五名鸟人的脚步声；三头猪人没有脚步声。

镜号 3
镜头语言：中近景 / 食堂内部正面斜拍 / 固定机位 / 赛几在前景转身欲走，领队A和B仅保留在后景两侧 / 用于赛几撇清与抓人者接近
画面描述：赛几站在食堂内部通道，顺手把塑料袋提环滑到腕部，再把双手搭到后脑，故作轻松地转身迈步；身体和袋子完整遮住侧口袋里的烧烤铲。领队A留在后方，B沿通道快步追近到赛几身后一步距离。
台词：赛几【随意、准备离开】：“你们来迟了！那个人已经逃跑了！”
音效：塑料袋窸窣声，鸟人B逐渐接近的脚步声。

镜号 4
镜头语言：中近景 / 赛几正面固定机位 / 固定机位 / 鸟人B的双手从赛几两侧肩后同时进入画面 / 用于突然抓停
画面描述：赛几刚跨出下一步，B的双手突然从背后同时扣住他的左右肩膀；赛几身体被稳稳停住，双手从后脑弹开，腕部的塑料袋轻晃但没有掉落。B已经进入接触距离，不从远处隔空抓人。
台词：无。
音效：短促抓握声，赛几急停的二维弹跳音。

镜号 5
镜头语言：近景 / 食堂入口侧面低机位 / 固定机位 / 野猪A昏迷的脸占下方主体，领队A的指尖停在方形铲印旁，铲印固定在画面左下位置 / 用于指证与建立方形图案
画面描述：【本镜只重新展示野猪A，野猪B、野猪C与猪王子固定在画外；A仍是开门镜中左侧倒地的同一头猪人】野猪A保持横躺昏迷且脸型、五官不变。领队A俯身指向其脸上浅红色的方形平面铲印，再抬眼瞪向被B抓住的赛几。
台词：鸟人领队A【认定、斥责】：“你当我傻吗？这不就是你干的！！”
音效：指尖停在铲印旁的短促强调音。

镜号 6
镜头语言：局部特写 / 从赛几视线方向俯拍侧口袋 / 固定机位 / 方形烧烤铲的铲面占据与上一镜铲印相同的画面位置和近似大小 / 用于图形对应与物证揭晓
画面描述：赛几低头看向自己被袋子遮挡过的侧口袋，发现方舟刚才使用的同一把方形烧烤铲正斜插在里面；方形铲面与把手清晰可辨，烧烤铲仍在口袋中且只有一把。画面不解释烧烤铲何时出现，只突出铲面与方形铲印形状一致。
台词：无。
音效：短促的惊觉提示音。

镜号 7
镜头语言：近景 / 食堂内部平视正拍 / 快速小幅前推 / 赛几炸毛暴怒的脸为主体，B的双手仍保留在双肩边缘 / 用于愤怒爆点
画面描述：赛几低头僵住一瞬，随即毛发炸起、额角绷紧，猛地转头朝敞开的玻璃门与校园室外方向大喊。B仍从背后扣住他的双肩，赛几没有挣脱，也没有冲回门口。
台词：赛几【暴怒、朝门外大喊】：“外卖佬！你给我回来！”
音效：赛几爆发的喊声，轻量二维震动强调音。

·  五名鸟人A、B、C、D、E必须使用完全相同的角色模型、鸟类五官、头型、羽毛、体型、制服、配色和身份标识，只靠固定站位与动作职责区分，禁止换脸、变脸、大小漂移或混入黑野猪特征。
·  领队A只负责敲门、质问、指向铲印和指证；同模鸟人B只负责追近并用双手抓住赛几双肩；同模鸟人C、D、E不说话、不抓人。镜号5只重新展示仍横躺的野猪A，野猪B、C与猪王子留在画外。
·  塑料袋提环从镜号3起连续挂在赛几腕部；同一把方形烧烤铲在镜号6前完全不可见，镜号5的方形铲印与镜号6的方形铲面必须占据相同画面位置，禁止提前露出、重复生成或被角色拿起；不展示食堂或室外大全景。

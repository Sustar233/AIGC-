# 第1集《尤卡降临》分镜脚本｜方舟食堂对峙（单元2）

- 剧本范围：原剧本“野猪A走上前”至方舟台词“要不要走后门给你们盖个检疫印章啊？”
- 制作模式：紧凑成片版（多人场景优化）
- 连续性处理：方舟全程站在靠近室外玻璃门的室内入口处，不向食堂深处移动；野猪A把举起的赛几向右侧推开后走向方舟，野猪B、野猪C跟在身后形成准备动手的推进队形。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第2单元 / 方舟、野猪A、野猪B、野猪C、赛几]
第 2 单元：三猪逼近与回呛
分镜类型：多人场景优化
场景：王子学院食堂入口通道与普通学生桌椅区
时间：日/内
出场人物：方舟、野猪A、野猪B、野猪C、赛几
时长：15 秒
画面综述：
王子学院食堂内，靠近室外的玻璃门位于画面左后方，方舟始终站在玻璃门内侧不远处，门体与室外光线保持在他身后可见。方舟一只手把一次性塑料外卖袋停在胸侧，方形烧烤铲仍别在腰部。野猪A在右侧前方举着正常比例的赛几，野猪B、野猪C在右后方错落站立。野猪A把赛几向画面右侧推开，随后带头沿入口通道走向方舟；野猪B、野猪C见状立即跟在A身后，形成A在前、B和C错落跟随的推进队形。赛几在右侧落地站稳，不进入三头野猪与方舟之间的通道。三头野猪同模同脸，均只比赛几高约半个头。方舟留在门口附近不退不进，抓着脑袋淡定说完整段回呛。相机保持方舟在左、三头野猪从右向左逼近的既有轴线。

镜号 1
镜头语言：中全景 / 平视侧拍 / 侧向跟拍 / 玻璃门与方舟保持在画面左侧，焦点跟随三头野猪从右向左推进 / 用于推开赛几、群体逼近与质问
画面描述：【锁定方舟站在玻璃门内侧不远处，三头野猪从右向左移动，赛几被推向画面右侧安全区域】野猪A抬臂把仍离地少许的赛几向右侧推开；赛几双脚落地后顺势踉跄两步站稳，体型不缩小。野猪A随即带头走向方舟，野猪B、野猪C见状一前一后跟上，在A身后错落推进。野猪A走到方舟前方一臂左右处停下质问，B、C停在其身后，三者只准备动手、不提前攻击。
台词：野猪A【恼怒、逼近质问】：“臭小子，你是个什么东西？”
音效：赛几落地与短促踉跄声，三头野猪由远及近的错落脚步声，野猪A加重的鼻息声。

镜号 2
镜头语言：中近景 / 越过野猪A肩侧的反打机位 / 缓慢前推 / 方舟与身后近处玻璃门保持同框，焦点锁定抓头动作与面部 / 用于淡定回应与身份说明
画面描述：【方舟固定留在玻璃门内侧不远处，野猪A在右侧近处，野猪B、野猪C错落站在A身后】方舟不后退，用空着的手抓了抓脑袋，同时平静看向野猪A并开口；外卖袋仍由另一只手持在胸侧，腰间烧烤铲不移动。
台词：方舟【淡定、平常口吻】：“我是兴趣使然的烧烤匠，食材超新鲜，”
音效：轻微抓头摩擦声，塑料袋窸窣声，方舟平稳的说话声。

镜号 3
镜头语言：中近景 / 平视侧面双人构图 / 固定机位 / 方舟位于左侧焦点，野猪A位于中右，二人之间保留少量对峙空间 / 用于方舟第二段回呛
画面描述：【方舟仍在玻璃门入口附近，野猪A停在中右近处，野猪B、野猪C保持在A身后，赛几位于右侧画外】方舟放下抓头的手，视线从野猪A扫向他身后的B、C，再回到A脸上。三头野猪压着眉头继续逼视方舟，但队形和距离不变，不提前出手。
台词：方舟【淡定、带轻微嫌弃】：“不会用你们这种看上去就臭的猪，”
音效：方舟平稳的说话声，野猪A压低的鼻息声，食堂环境音持续。

镜号 4
镜头语言：近景 / 平视略低机位 / 固定机位 / 焦点锁定方舟的平静眼神，玻璃门边框保留在左后方，野猪A肩部位于右侧前景 / 用于“检疫印章”台词落点
画面描述：【方舟、玻璃门与三头野猪的相对站位不变，相机不越轴】方舟微微偏头，视线落回野猪A脸上，把最后一句完整说完。野猪A只收紧眉头和鼻息，野猪B、野猪C保持在身后准备动手；方舟的外卖袋和腰间烧烤铲均保持原位。
台词：方舟【淡定、轻微挖苦】：“要不要走后门给你们盖个检疫印章啊？”
音效：方舟平稳的说话声，野猪A压住的鼻息声，食堂环境音持续。

其他要求：
·  镜头时长估算：镜号1 0-3秒；镜号2 3-7秒；镜号3 7-11秒；镜号4 11-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识。
·  不加字幕。
·  本单元固定角色为方舟、野猪A、野猪B、野猪C、赛几；方舟全程留在靠近室外玻璃门的入口处，玻璃门保持在他身后近处，轴线锁定为方舟在左、三头野猪从右向左逼近。
·  三头野猪必须同模同脸、同体型和同外观，只靠队形位置区分；均只比赛几高约半个头、躯干略宽，禁止变脸、巨型化或缩小赛几。
·  野猪A把举起的赛几推向右侧，赛几落地站稳；随后A带头、B和C错落跟随走向方舟，最终A在前、B和C在后，只准备动手，不提前攻击。
·  方舟的外卖袋不换手、不掉落，烧烤铲仍别在腰部；本单元完整说完两句原始台词并停在“打他！”之前，保持纯二维少儿动画，不出现写实或三维质感。

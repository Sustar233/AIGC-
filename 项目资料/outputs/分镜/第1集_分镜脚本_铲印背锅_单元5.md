# 第1集《尤卡降临》分镜脚本｜铲印背锅（单元5）

- 剧本范围：原剧本第81-88行“咚咚咚”至赛几“外卖佬！你给我回来！”
- 制作模式：紧凑成片版（多人场景优化）
- 构图限制：全程只使用中景、中近景、近景或局部特写，不给食堂或室外大全景；五名鸟人只在门口建立镜中完整点数，后续每镜仅保留当前动作所需人物；三名倒地猪人中只展示一名昏迷猪人的脸部铲印。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第5单元 / 赛几、鸟人领队A、鸟人执勤人员B、鸟人执勤人员C、鸟人执勤人员D、鸟人执勤人员E、野猪A]
第 5 单元：铲印背锅
分镜类型：多人场景优化
场景：王子学院食堂外墙玻璃门内侧入口通道与门槛
时间：日/内
出场人物：赛几、鸟人领队A、鸟人执勤人员B、鸟人执勤人员C、鸟人执勤人员D、鸟人执勤人员E、野猪A
时长：15 秒
画面综述：
赛几仍在食堂室内，塑料外卖袋的提环挂在腕部，方形烧烤铲已藏在其侧口袋中但揭晓前不得露出。关闭的外墙玻璃门外是校园室外，五名鸟人执勤人员以领队A居前、B至E错落在后的队形敲门；领队推门进入，另外四名跟到门内门边。赛几转身欲走时，B从背后抓住其双肩；领队以昏迷野猪A脸上的方形铲印指证赛几，赛几低头发现口袋里的烧烤铲后暴怒。

镜号 1
镜头语言：中近景 / 食堂室内正对关闭玻璃门上半部 / 固定机位 / 透过玻璃锁定门外五名鸟人的五个独立头肩轮廓 / 用于敲门与人数建立
画面描述：【玻璃门内是食堂，门外是有自然日光的校园室外；镜头只拍门的上半部，不拍门口地面】领队A站在门外最前方抬手敲击玻璃，鸟人B、C、D、E分成前后两层站在其身后；五人头肩轮廓均完整可辨、互不重叠，赛几听见声音后从门内侧转头。
台词：无。
音效：三下清楚的敲门声“咚、咚、咚”。

镜号 2
镜头语言：中景 / 食堂室内斜对门口 / 轻微后移 / 领队A居中，B至E在门边错落露出完整上半身，赛几只留肩部前景 / 用于执勤人员进入与质问
画面描述：领队A推开玻璃门跨过门槛进入食堂，B、C、D、E紧随到门内门边停下；门外仍清楚是校园室外，五名鸟人均已位于可接近赛几的室内一侧。领队A扫视入口通道，厉声质问。
台词：鸟人领队A【严厉、护短】：“是谁？谁袭击我可爱的学生！”
音效：玻璃门开启声，五人短促整齐的脚步声。

镜号 3
镜头语言：中近景 / 室内平视侧拍 / 固定机位 / 赛几为主体，门边五名鸟人仅保留领队A与B的肩部边缘 / 用于赛几撇清后离开
画面描述：赛几把双手搭到后脑，塑料袋提环仍挂在腕部，故作轻松地转身朝食堂内部迈步；他的身体与袋子遮住侧口袋，烧烤铲不得提前露出。领队A盯住赛几，B从门边开始跟近。
台词：赛几【随意、准备离开】：“你们来迟了！那个人已经逃跑了！”
音效：塑料袋随手臂轻晃的窸窣声，赛几迈步声。

镜号 4
镜头语言：中近景 / 赛几背后侧拍 / 快速小幅前推 / 焦点锁定鸟人B的双手与赛几双肩接触点 / 用于突然控制
画面描述：【鸟人B已从门边进入赛几身后一步距离】赛几刚迈出一步，B突然伸出双手同时扣住赛几左右肩膀，把他稳稳留在原地；赛几上身一顿，双手从后脑弹开，腕部塑料袋仍未掉落。
台词：无。
音效：短促抓握声，赛几急停的二维弹跳音。

镜号 5
镜头语言：中近景 / 室内低位斜拍 / 固定机位 / 野猪A昏迷的脸位于下方前景，领队A的指尖与方形铲印形成同一视觉焦点，赛几和B只留上半身边缘 / 用于证据指认
画面描述：【只展示野猪A，野猪B与野猪C固定在镜头裁切外】领队A走到昏迷的野猪A旁，伸手指向其脸上轮廓清晰的浅红方形铲印，再转眼瞪向被B抓住的赛几。野猪A保持昏迷、五官与脸型不变。
台词：鸟人领队A【认定、斥责】：“你当我傻吗？这不就是你干的！！”
音效：领队指尖停下的短促强调音，食堂入口环境音压低。

镜号 6
镜头语言：局部特写 / 从赛几视线方向俯拍侧口袋 / 固定机位 / 焦点锁定口袋里唯一一把方形烧烤铲 / 用于物证揭晓
画面描述：赛几顺着领队的指向低头，看见自己侧口袋里斜插着方舟刚才使用过的同一把方形烧烤铲，方形铲面与把手清晰可辨；烧烤铲只出现一把，仍在口袋中，没有被任何人拿起。
台词：无。
音效：短促的惊觉提示音。

镜号 7
镜头语言：近景 / 室内平视正拍 / 快速小幅前推 / 赛几炸毛暴怒的脸为焦点，鸟人B双手仍搭在其肩部边缘 / 用于愤怒收尾
画面描述：赛几先僵住，随即头顶毛发完全炸起，额角绷紧，猛地扭头朝敞开的玻璃门与校园室外方向大喊；B仍扣着他的双肩，赛几没有挣脱或冲出门外。
台词：赛几【暴怒、朝门外大喊】：“外卖佬！你给我回来！”
音效：赛几爆发的喊声，轻量二维震动强调音。

其他要求：
·  镜头时长估算：镜号1 0-1秒；镜号2 1-4秒；镜号3 4-7秒；镜号4 7-8秒；镜号5 8-12秒；镜号6 12-13秒；镜号7 13-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识。
·  不加字幕。
·  玻璃门开场完全关闭，敲门后由领队A推开；五名鸟人按A、B、C、D、E固定身份与站位出现，镜号2结束后均在门内，后续未入镜者固定留在门边画外，禁止漏人、复制增员或把门外生成成室内空间。
·  领队A负责质问、指向铲印和指证台词；鸟人B负责从背后以双手抓住赛几双肩；C、D、E不说话、不抓人，禁止同一角色同时双手抓肩又伸手指证。
·  只允许野猪A在镜号5作为昏迷伤者出镜，脸上保留方形平面铲印且不变脸；野猪B、C与猪王子固定在画外，不展示餐桌区、其他食客或室外大全景。
·  赛几的塑料袋提环全程挂在腕部且不掉落；同一把方形烧烤铲在镜号6前必须完全遮住，镜号6才从赛几侧口袋首次露出，禁止提前穿帮、凭空增殖或被其他角色拿在手中。

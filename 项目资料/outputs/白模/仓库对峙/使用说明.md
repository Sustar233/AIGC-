# 仓库对峙分镜白模

依据用户图片“上半.png”搭建，用于构图、人物站位、遮挡和空间纵深预演。单张图无法确定的尺寸、背面及空间结构为近似设计；人物为姿态白模，没有精细角色绑定或动画。

- 场景文件：仓库对峙_分镜白模.blend
- 主机位预览：参考机位_白模.png
- 正式白模场景：仓库对峙_参考图白模。原来的默认 Scene 仍保留。
- CAM_01_参考图背拍：对应参考图的主要构图。
- CAM_02_空间总览：检查仓库和角色整体布局。
- 集合按仓库结构、前景人物、机械蛛、碎石残骸、机位与灯光分类。
- 调整人物或机械蛛的整体位置时，选择名称含“整体移动”的空物体；其模型部件会一同移动。
- 原始参考图已打包到工程中，主相机保留关闭状态的参考背景图，可按需开启对照。

本次通过 Blender MCP 直接创建并保存，独立于工作区现有二维叙事项目的设定数据库。

# 仓库对峙｜对白与火淬刀

独立片段，无正式集数。总预演21秒，分为12秒与9秒两个可独立生成的连续单元。白模为16:9横屏，使用本次用户明确要求的三维白模，不套用工作区其他项目画风。

名称备注：右侧红蛛的资产名按用户末尾说明统一为“腥日蛛”；陈默台词里的“猩日蛛”保留原文，待文字定稿时统一。“昆虫”保留为月织原台词，不作为生物分类设定。公母对应哪一只未指定，不增设。

人物锁定：陈默为左前景束发男性，右手为主手，左手辅助握刀；月织为右前景双束发女性，右手持匕首。腥月蛛在左侧深处，蓝色识别点；腥日蛛在右侧深处，红色识别点。两蛛沿用已确认的1.5倍体型与后移8米的位置。陈默攻左，月织进右，月织先启动，路线不交叉。

正式声线：两人均待确认。交付的白模视频无音轨、不配口型，台词留足时间，通过同名SRT核对；以下音效是成片制作要求。

画面风格：
三维灰白几何白模，保留原参考图的人物轮廓、仓库立柱与纵深。蜘蛛仅使用蓝、红识别点；火淬刀使用贴附刀刃的橙色简化火焰示意。清晰轮廓，均匀灰白照明，无纹理细节，无字幕，16:9横屏。

月织持匕首已在右侧通道起跑，陈默双手持刀位于左前景。左蓝腥月蛛与右红腥日蛛留在仓库深处。陈默随后蹬地冲向左蓝蛛，月织继续奔向右红蛛。机位由后方全景转入陈默右后侧手部，再扩大到陈默与左蛛的有效距离，持续保持同侧轴线。陈默在接近左蛛时扭动把手，刀刃出现火淬示意；进入刀长可及的位置后踏稳前脚，双手举刀并向蜘蛛头部落下。落幅停在刀刃抵达头部表面，不表现伤口、倒地或胜负。

镜头语言：全景 / 双人后方略高机位 / 前推 / 两条不交叉的冲锋路线 / 明确先后与目标。

# 固定画风说明

本目录保存用户于 2026-08-05 明确提供的 9 张画风参考图，源文件未覆盖。

## 固定风格锚点

- 清新儿童向二维手绘卡通。
- 圆润简化的角色与场景造型，低细节几何结构。
- 略带手绘抖动感的深灰细描边。
- 柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主。
- 大面积平涂，叠加轻微纸张颗粒、彩铅或水彩晕染质感。
- 弱阴影、低对比、高明度，构图直观并保留适量留白。
- 默认使用 16:9 横向画幅。
- 夜景只调整明度与冷暖关系，不改变线稿与平面化规则。
- 保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

## 提示词版本

- 精简版：只保留固定画风、必要制图规范和剧本直接要求的元素。
- 扩展版：可在不改变项目事实与固定锚点的前提下补充构图、空间、材质、光影、氛围和可复用细节。
- 每条人设图、场景图、生物、灵体和关键道具提示词必须以“生成4次，每次返回不同图片。”结尾，后面不得追加内容。

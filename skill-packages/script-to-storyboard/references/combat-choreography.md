# 战斗、追逐与能力动作链

动作设计服务既定剧情。不得改变台词、人物、胜负、伤势、武器、能力或场地事实。

## 战斗事实锁

先确认：

- 剧情节点、持续时间与不可改变结果。
- 双方能力/武学、惯用手、武器、能力源点、当前伤势和限制。
- 初始位置、朝向、距离、高低差、移动空间和 180 度轴线。
- 场地已有可交互物与禁止破坏物。
- 胜负、受伤、武器脱手、能力耗损和场景破坏的终局状态。

缺失项会改变胜负或动作成立条件时暂停确认；否则采用最保守动作，不新增技法或装备。

## 动作链语法

每个主要动作交代完整因果：

```text
[发起者] + [身体部位/武器] + [起势与发力点] + [移动方向/三维轨迹] + [攻击目标/落点] + [防守方式] + [接触反馈] + [受力位移] + [结果状态]
```

禁止只写“快速连击”“激烈交锋”“释放大招”。每次接触都写清攻击与防守如何相遇、谁改变重心以及如何进入下一拍。

## 连续性与力学

1. 让下一动作从上一动作的脚位、重心、手位、武器位置和视线自然起势，禁止瞬间复位。
2. 让攻击方进入有效距离后再命中；防守方必须有格挡、闪避、截击、卸力、失衡或被命中的可见反馈。
3. 重击、格挡、摔投或能力碰撞至少写清发力链、接触点、力量方向、防守反馈、环境反馈和结果确认。
4. 摔投依次写控制点、破坏重心、旋转轴、离地、落点和落地反馈；禁止反关节穿插或无起身过程瞬间站立。
5. 武器持续锁定持握手、刃口/枪口方向、攻击弧线、接触点和脱手后的去向。
6. 追逐持续锁定领跑者、追击者、速度差、前进方向、障碍路径和交换位置的可见依据。
7. 终结必须由前面的破绽、失衡、耗损或空间限制自然导出，并留出结果确认镜头。

## 短时长节奏参考

约 15 秒且剧本没有更强拍点时可采用：

- 0—2 秒：直接进入冲突或临界状态。
- 2—5 秒：建立第一轮攻防和双方动作特征。
- 5—9 秒：位置、武器或主动权变化。
- 9—13 秒：关键破绽与高强度动作。
- 13—15 秒：终结、落地和结果确认。

台词与剧本拍点优先。不要为动作密度牺牲可辨认的起势、接触和结果。

## 能力与特效

按下列链路绑定特效：

```text
[固定能力源点] → [沿身体/武器聚集] → [随动作形成形态] → [三维轨迹] → [接触变化] → [余波与消散]
```

- 持续锁定能量颜色、材质、粒子尺度、速度、范围和源点。
- 挥击与剑气/冲击波在同一镜号绑定；写清向远处变宽、延伸或平推。
- 碰撞写清交界面如何推进、弯折、破裂、偏转或抵消。
- 爆炸、碎屑、液体和粒子写明朝镜头、向外、向远处或沿 Z 轴的轨迹。
- 重组、复原、异化和极速位移提供至少约 0.5 秒的可见物理中间态。
- 避免爆衣、肌肉膨胀、皮肤开裂等高穿帮表达；用空气折射、电弧、粒子牵引、地表受力等既定能力反馈表现强度。
- 特效不得遮住关键肢体、接触点或表情。

## 战斗运镜与多人战斗

- 每镜只用一个核心运镜，并让景别匹配动作幅度：细部接触用中近景，大位移、腾空和摔投用中景或全景。
- 高速镜头仍保留清楚的起势、接触和结果，不用全程运动模糊遮掩动作。
- 多人战斗每次只突出一个主要攻防关系；其他人保持明确站位、牵制或画外状态。
- 群攻按威胁顺序切片，禁止所有人无序同时扑向中心。
- 把友军、平民和禁止破坏物纳入攻击轨迹与镜头安全检查。

# 正式分镜输出格式

每个单元完整重复画面比例、画面风格与目标模型，保证单元可单独复制给视频模型。不要写“同上”。

```markdown
画面比例：16:9 横屏宽画幅（或用户明确指定的比例）
画面风格：[依据用户设定或已确认风格完整书写]
目标模型：[Seedance 2.0 或用户指定模型]

## 第X集-第Y单元
单元名称：[本单元剧情功能，不新增剧情]
分镜模式：快速版 / 标准版 / 精细版
分镜类型：普通对白 / 情绪表演 / 多人场景优化 / 战斗分镜优化 / 剪辑版候补
场景：[剧本地点]
时间：[日/夜，内/外]
出场人物：[全部可见或发声人物；群像写明人数]
时长：[1—15]秒

画面综述：
[用可见、物理化语言独立交代当前场景、全部人物、初始站位、视向、关系、关键道具和本单元起承转合。不要用前情代称。]

### 镜号 1
镜头语言：[景别 / 机位角度 / 一个核心运镜 / 构图与焦点 / 镜头功能]
画面描述：[必要的视向、姿态或轴线锁定 + 一个核心动作/反应 + 可见表演或力学反馈 + 客体方位]
台词：[无；或 角色名【情绪，语速】：“剧本台词”；OS 必须明确标注]
音效：[环境声 / 动作声 / 接触声 / 能量声；没有则写“无新增音效”]

### 镜号 2
镜头语言：
画面描述：
台词：
音效：

其他要求：
- 镜头时长估算：镜号1 0-3秒；镜号2 3-7秒；……（整数秒、连续、合计等于单元时长且不超过15秒）
- 保留与场景一致的真实环境声和必要动作音效。
- 纯净画面，无任何文字、Logo 或水印；默认不加字幕，除非用户明确要求。
- [本单元必要的画幅、角色一致性、轴线、道具或特效约束；不要写空泛口号。]
```

## 填写规则

1. “画面风格”不得只写风格名。写清媒介/写实程度、材质、光影、色调、景深、画幅和角色稳定性，但不要借风格新增场景物件。
2. “画面综述”建立单元初始状态，不代替逐镜动作。
3. “镜头语言”只写摄影机；人物表情、走位和动作全部进入“画面描述”。
4. “台词”保持发言者、文字、OS 属性和情绪节奏。跨镜延续声音时标注 `L-cut`。
5. 每个镜号只承载一个主因果链。独立人物反应另拆镜号。
6. 镜头时间段只在“其他要求”第一项统一汇总，不写在镜号标题中。
7. 每个单元都完整写出“其他要求”，不得使用“同上”或省略号代替固定字段。
8. 默认输出简体中文 Markdown；用户指定其他语言或表格格式时再调整。
9. 单元标题推荐使用 `## 第X集-第Y单元`；已有工作流使用 `## [第X集-第Y单元]` 时可以继续保留方括号，但同一项目内必须统一。

完成本批所有单元后，按 [输入与连续性](input-and-continuity.md) 附“批次连续性末态”。用户明确要求“只给可复制提示词”时，可以把连续性末态放在所有单元之后，避免混入单元提示。

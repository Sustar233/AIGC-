# 多人场景调度与连续性

当一个单元出现 3 名及以上可见角色，或存在队伍、围观、多人对白、包围、群像反应或多人移动时执行全部规则。

## 内部站位图谱

生成前锁定：

- 画面左/中/右。
- 前景/中景/背景。
- 每人的朝向、视线对象、相互距离和出入口。
- 主要对话或冲突轴线。
- 暂时画外但仍在场的人物及其位置。

不要为了构图把人物自动排成一排。使用前后错落、左右分层或局部三角构图，但不得新增剧本外走位。

## 人数与画面负载

1. 让出场人物栏、画面综述、镜头描述、声音来源和连续性末态中的人数一致。
2. 只在建立空间、集体转身、队伍移动或关键围堵时使用全员全景。
3. 普通多人对白优先使用 1—2 人中近景、越肩、单人反应、焦点分层或合理前景裁切。
4. 未入画角色必须注明仍在固定画外位置或被摄影机裁切；不要让其无解释消失、离场或换位。

## 邻接与接触

拍肩、拉手、递物、搀扶、耳语、制服、击倒等动作发生前，确认两人已经相邻。若不相邻：

1. 先用独立镜头展示发起者沿明确、无遮挡的路径移动。
2. 更新其新位置、朝向和与他人的距离。
3. 再在下一镜完成接触。

禁止隔着第三人或跨越不可能距离直接完成接触。

## 对话与反应

- 明确说话者、直接听者、旁观者和画外人员的视线方向。
- 不让所有人同时看镜头。
- 群像反应按“主反应者 → 次反应者 → 群体压力/沉默”拆镜，不塞进一个镜号。
- OS 不触发群体反应。

## 连续性检查

- 人物移动后的新站位是否被后续镜头继承。
- 正反打是否保持左右关系与视线方向。
- 进出场是否经过剧本已有入口并有可见过程。
- 接触双方是否物理相邻。
- 背景人物是否被合理裁切而非消失。
- 道具交接后持有人与手位是否更新。
- 倒地、退场或失去行动能力后，后续人数与状态是否同步更新。

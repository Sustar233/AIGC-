# 表演、对白与镜头语言

## 可见表演

情绪词只能作为方向锚点，后面立刻跟可见动作。关键情绪镜使用：

```text
刺激 → 本能反应 → 控制/掩饰 → 最终表情与姿态
```

从下列维度选择与景别最匹配的 1—3 类，不要每镜全部堆满：

- 视线：看向谁或何物、移开、停住、失焦、重新对视。
- 眉眼：眉心收紧、眼皮压低、眨眼变慢、短暂睁大。
- 嘴部/下颌：嘴角收平、唇微张又停、下颌绷紧、喉结滚动。
- 呼吸/停顿：呼吸停一拍、吸气变短、吐气变轻、开口前停顿。
- 手部：动作中断、指尖收紧、握住已有物件、手停在半空。
- 重心/姿态：后撤、压低重心、肩线变化、身体僵住、转身中断。

普通对白和过场只选一个核心动作或表情。重大反转、崩溃或极近特写才使用完整变化链。相邻镜头不要机械复用同一组微表情。

禁止“眼神里写着……”“气场压过全场”“时间仿佛停止”等不可见心理或抽象结论。把它们改为摄像机能记录的动作与环境结果。

## 景别匹配

- 远景/全景：写站位、距离、动线、重心和人物与环境关系；不写瞳孔细节。
- 中景/中近景：写对话关系、头部角度、视线、手部与身体动作。
- 近景/特写：写眉眼、嘴部、呼吸和表情变化轨迹。
- 极特写：只拍关键接触点、指尖、眼睫、喉结或剧本关键物件。

## 台词、L-cut 与 OS

1. 按情绪语速估算台词，不为塞入 15 秒而强行加速。
2. L-cut 只用于现场真实发声且听者物理上能听见的台词。画面可切到听者反应，声音继续承接说话者。
3. OS 是内心声音，其他人物听不见。不得因为 OS 安排他人回头、震惊或接话；可配发言者自身细节、客观常态或环境/道具镜头。
4. 旁白、广播、电话、隔墙声等必须标明声源和可听范围。

## 镜头语言

使用以下顺序：

```text
景别 / 机位角度 / 一个核心运镜 / 构图与焦点 / 镜头功能
```

常用运镜与功能：

- 固定机位：沉默、压迫、反应落点。
- 缓慢前推：压力增强、真相逼近。
- 缓慢后拉：抽离、失落、关系疏远。
- 侧向跟拍：人物移动与空间推进。
- 焦点转移：关键物件到表情、说话者到听者。
- 快速甩镜：突发信息或冲突爆点；只短促使用。
- 轻微手持：紧张与不稳定；不要掩盖动作缺失。
- 前景揭示/遮挡转场：登场、空间揭示或自然切换。

一个镜头只用一个核心运镜，不堆叠“推近 + 环绕 + 旋转 + 变焦”。焦段和光圈仅在确实帮助生成时填写。

## 构图与轴线

- 双人对峙保留视线方向留白和中间冲突空间。
- 反打保持人物左右关系；越轴前用可见过轴镜头建立。
- 横屏强调前中后景与空间关系；关键头部、肢体和武器远离画幅边缘。
- 竖屏若由用户明确指定，则优先人物面部可读、头顶安全留白和中近景；不要在同一批混用横竖比例。
- 不写真实品牌 Logo 或可读文字，除非剧情明确需要且用户接受文字生成风险。

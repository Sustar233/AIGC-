# 剪辑 B 版与候补镜头

把“剪辑版”“B 版”“候补镜头”“平行交叉剪辑版”理解为可逐镜替换、也能独立顺播的平行分镜，不是 EDL、剪辑时间表或零散补镜列表。

## 硬性对齐

B 版必须与 A 版保持：

- 相同单元总时长。
- 相同剧情顺序和因果。
- 相同台词文字、发言者、OS 属性与起止节点。
- 相同关键动作、角色状态、站位、轴线、惯用手、道具和环境状态。
- 默认相同镜号数量与时间区间；确需改变镜数时，所有关键节点仍须在时间轴上可对应。

## 必须产生的差异

每个候补镜头显著改变至少一项：景别、机位、运镜、构图、焦点主体或可见动作中间态。不要只替换近义词。

优先补偿 A 版的高风险素材：

- 接触点或动作中间态。
- 单人局部动作与关键手位。
- 听者反应或主观视角。
- 环境受力结果。
- 复杂多人场景中的 1—2 人降载镜头。

不得借 B 版新增角色、台词、伤势、胜负、走位或环境物件。

## 输出方式

继续使用正常分镜的完整格式，把标题改成：

```text
## 第X集-第Y单元·剪辑B版
```

B 版所有镜头顺序连播时必须独立、连贯地覆盖原剧情；不得只列可插入的碎片素材。只有用户明确要求 EDL、成片时间线或剪辑操作说明时，才改用剪辑表。

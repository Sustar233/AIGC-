# 画面风格选择

优先沿用用户明确指定或已经确认的人设/场景风格。不要因为旧项目或示例使用过某种风格而自动继承。

用户未指定时，先根据题材推荐最匹配的一种；如果用户明确要求直接生成，则采用最保守、最贴合剧本的方向，并在输出中把它标记为本批假设：

| 题材 | 可选方向 |
|---|---|
| 都市、职场、生活 | 现代都市写实电影风格 |
| 家庭、治愈、成长 | 温暖现实主义电影风格 |
| 乡村、年代 | 乡村现实主义暖灰电影风格 |
| 悬疑、犯罪、心理 | 冷峻低饱和悬疑电影风格 |
| 强冲突、复仇 | 高对比戏剧电影风格 |
| 文艺、孤独、疏离 | 柔和清冷情绪电影风格 |
| 日常、轻喜剧 | 暖调生活电影风格 |
| 古装、历史 | 古装写实电影风格 |
| 商战、权谋 | 克制高级现实电影风格 |
| 动漫、奇幻、超能 | 依据用户资产选择 2D 动漫、2.5D 或 3D 写实动漫；不要擅自混合 |

风格句至少说明：

- 影像媒介与写实程度。
- 角色与材质表现。
- 主色调、对比度与光影方向。
- 景深、空间层次与画幅。
- 角色外观、服装、道具和能力特效保持稳定。

使用视频模型容易理解的结果型语言，避免堆叠摄影机、胶片、引擎和后期术语。画风只能改变表现方式，不能改变剧本时代、场景、人物外观或物件。

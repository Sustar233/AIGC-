# 第1集《尤卡降临》分镜脚本｜方舟食堂反击（单元3·扩充前备份）

- 剧本范围：原剧本“野猪怒吼道：【打他！】”至“啪啪啪三连击！三头猪直接被打飞！”
- 制作模式：多人战斗精细版
- 动作边界：只表现三头野猪依次进入攻击距离、方舟取出腰间烧烤铲完成三次单拍并将三者击飞，不新增招式、能力、伤势或场景破坏。
- 节奏方向：二维少儿动画的清晰快节奏，起势短、接触点明确、每次击飞都有独立结果，不使用写实重击、复杂缠斗或三维游戏式运镜。

画面风格：
清新儿童向二维手绘卡通：角色与场景采用圆润简化造型和低细节几何结构，略带手绘抖动感的深灰细描边，柔和明亮的粉彩低饱和配色，以浅米白、浅绿、浅蓝和浅暖色为主，大面积平涂结合轻微纸张颗粒、彩铅或水彩晕染质感，弱阴影、低对比、高明度，构图直观并保留适量留白，默认16:9横幅；夜景仅调整明度与冷暖关系，保持相同线稿和平面化规则；保持纯二维，不使用写实、3D、厚涂或厚重电影光影。

[第1集-第3单元 / 方舟、野猪A、野猪B、野猪C、赛几]
第 3 单元：三拍击飞
分镜类型：战斗分镜优化（精细版）
场景：王子学院食堂入口通道与普通学生桌椅区
时间：日/内
出场人物：方舟、野猪A、野猪B、野猪C、赛几
时长：15 秒
画面综述：
王子学院食堂内，靠近室外的玻璃门位于画面左后方，入口通道中央保持无遮挡。方舟站在画面左侧室内通道，身体朝向右侧冲突区，一只手继续把一次性塑料外卖袋稳稳持在胸侧，另一只手空着，方形烧烤铲仍别在腰部。野猪A站在中右一臂左右处，野猪B与野猪C在右后方前后错落，赛几站在更右侧、避开方舟与三头野猪之间的攻击通道。三头野猪使用完全相同的固定角色模型、五官、体型、毛色、校服与头顶标识，均只比赛几高约半个头、躯干略宽。野猪A怒吼下令后，三头野猪按A、B、C的顺序进入有效攻击距离，不同时围扑。方舟用空着的手从腰间取出烧烤铲，以铲面依次拍中三头野猪的面颊；每次接触只使用平面化短促速度线和星形撞击闪光强调节奏，三头野猪沿右后方无遮挡区域依次飞出并分散落地，脸部轮廓始终不变，只留下剧情要求的浅红方形铲印。相机全程位于既有对峙轴线同一侧，保持方舟在左、攻击者从右侧进入、击飞方向朝右后方。猪王子、食堂阿姨及其他食客保留在既有画外位置，不入镜、不离场。

其他要求：
·  镜头时长估算：镜号1 0-2秒；镜号2 2-4秒；镜号3 4-6秒；镜号4 6-9秒；镜号5 9-12秒；镜号6 12-15秒。
·  全程使用白噪音作为背景氛围。
·  保留真实环境音。
·  保留动作音效。
·  纯净画面，无任何文字标识，三次“啪”只作为声音出现，不生成拟声文字。
·  不加字幕。
·  本单元固定角色集合为5名：方舟、野猪A、野猪B、野猪C、赛几；局部镜头未入画角色均为摄影机裁切或处于明确画外轨迹，不得被生成成离场或消失。
·  三头野猪必须同模、同脸、同体型、同毛色、同校服、同头顶标识；全程锁定五官比例和轮廓，禁止变脸、串脸、换脸、脸型漂移、颜色漂移和体型漂移。浅红方形铲印仅作为平面色块叠加，不得改变脸部几何轮廓。
·  三头野猪与赛几保持接近体型，野猪仅高约半个头、躯干略宽；禁止野猪巨型化，禁止缩小赛几，禁止出现抓取玩偶式比例。
·  三头野猪严格按A、B、C顺序进入有效攻击距离；前一名被拍离通道后，后一名才能上前。禁止三者同时围扑、互相穿模或在同一落点重叠。
·  每次拍击只包含清楚的起势、铲面接触、单一受力方向和独立飞出结果；撞击表现采用短促二维速度线、平面星形闪光和轻量弹性回弹，不使用写实伤口、血液、骨折、关节扭曲或痛苦特写。
·  方舟不释放能力，不新增招式或武器；烧烤铲始终由原本空着的手持握，外卖袋继续由另一只手持在胸侧，不换手、不掉落。三连击结束后烧烤铲保持在方舟手中。
·  三头野猪的飞行与落地限定在右后方无遮挡区域，不撞击赛几、桌椅、玻璃门或其他食客，不造成场景破坏。
·  动作节奏符合二维少儿动画：轮廓清楚、姿态简洁、接触帧可辨、喜剧感强；禁止写实格斗质感、三维建模体块、游戏引擎渲染、复杂旋转镜头、长时间运动模糊或沉重暴力氛围。
·  本单元完整覆盖“打他！”、方舟取出烧烤铲、一拍一个及三头野猪被打飞，并停在赛几的内心独白之前。
·  台词栏只保留角色、必要情绪和原始台词，不写字速数值、剪辑术语或时长参数。

# 项目规则入口

- 工作区通用约束见根目录 [AGENTS.md](../AGENTS.md)。
- 当前项目事实、画风和路径见 [project.json](../project.json)。
- 项目专属分镜要求见配置 `paths.storyboard_rules` 指向的文件；未配置时按通用规则执行。
- 用户本轮明确要求及已确认的项目专属要求决定具体输出格式；出现未能解释的实质冲突时先确认，不能用旧项目记忆补全。
- 正式制作按需读取对应技能。续写只补充当前剧情行、对应缓存、上一批末态及当前出场资产；参考图与已确认锚点在同一任务内复用。
- 镜头末态、删改台词和下一句只在相应连续性缓存维护。此入口不复制画风全文、角色设定、制作偏好或剧情状态。

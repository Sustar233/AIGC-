# AI 视频战斗动作设计（优化前备份）

把已经确定的剧情节点转换为可拍摄、可生成、物理连续的战斗动作链。动作设计服务剧情，不改变台词、人物、胜负、伤势或场地事实。

## 配置与协作模式

1. 读取 project.json 的视频模型、默认视觉风格和工作流设置。
2. 由 storyboard-director 调用时，只接收战斗调用单并返回动作方案；不要重新拆剧情单元或包装完整分镜。
3. 独立使用时，先锁定时长、双方能力、初始站位、场地与既定结果。
4. 单次能力展示、短促推搡或普通走位交回 storyboard-director，不展开完整战斗协议。
5. 示例动作只能作为结构参考，不得自动赋予角色未确认的技法、能力、颜色或装备。

## 战斗调用单

输入至少包含：

- 剧情节点与不可改变的结果。
- 单元总时长。
- 角色A/角色B的能力、武学、惯用手、武器、能力源点和当前伤势。
- 初始位置、朝向、距离、高低差和移动空间。
- 场地可交互物及禁止破坏物。
- 胜负、受伤、武器脱手、场景破坏等终局状态。
- 禁改项和穿帮风险。

信息缺失会改变胜负或动作成立条件时，必须反馈给调用方确认。缺少非关键细节时采用最保守方案，不新增设定。

## 动作链语法

每个动作写全以下因果字段：

~~~text
[发起者] + [身体部位/武器] + [起势与发力点] + [移动方向和三维轨迹] + [攻击目标/落点] + [防守方式] + [接触反馈] + [受力位移] + [结果状态]
~~~

禁止只写“快速连击”“激烈交锋”“释放大招”。每次接触必须说明攻击与防守如何相遇、谁改变重心、动作如何进入下一拍。

## 动作连续性

1. 起势必须来自上一动作末态：脚位、重心、手位、武器位置和视线连续。
2. 进攻必须给防守方留下可见反应：格挡、闪避、截击、卸力、被命中或失衡。
3. 防守后的手臂、武器与身体位置必须进入下一动作，不能瞬间复位。
4. 摔投写清控制点、破坏重心、旋转轴、离地过程、落点和落地反馈。
5. 武器动作锁定持握手、刃口或枪口方向、攻击弧线、接触点和脱手后的去向。
6. 追逐锁定领跑者、追击者、速度差、障碍路径和空间方向，不能无动作交换前后位置。
7. 终结动作必须由前面的破绽、失衡、耗损或空间限制自然导出。
8. 角色移动后立即更新距离、朝向和轴线；下一动作不得恢复旧站位。
9. 角色已受伤、被控、武器损坏或能力受限时，后续动作必须体现限制。

## 短时长节奏

当时长约 15 秒且剧情没有另行规定时，可使用以下骨架：

- 0—1.5 秒：直接进入冲突或高压临界点，不做无关环境铺垫。
- 1.5—5 秒：建立双方动作签名和第一轮攻防。
- 5—9 秒：位置、武器或攻守主动权发生变化。
- 9—13 秒：关键破绽与高强度动作。
- 13—15 秒：终结、落地和结果确认。

调用方给出的台词、剧情拍点和单元时间优先。不要为追求密度塞入无法辨认的动作；普通攻防每拍只保留一个主因果链。

## 力学与受力反馈

每个重击、格挡、摔投或能力碰撞至少交代：

1. 发力链：支撑脚、髋肩转动、手臂、武器或能力源点。
2. 接触点：身体部位、武器部位或能量交界面。
3. 力量方向：前后、左右、上下及旋转方向。
4. 防守反馈：震颤、卸力、滑步、屈膝、偏转、失衡或被击飞。
5. 环境反馈：只使用剧本已有地面、墙体、尘土、水体或可破坏物。
6. 结果确认：站位、伤势、武器和场景状态明确落定。

动作幅度与景别匹配：拳、掌、肘、腕和面部反馈优先中近景；奔跑、腾空、旋转、摔投和大范围能力优先中景或全景。

## 常见动作类型

### 徒手近战

- 用明确招式链替代“连续出拳”：攻击部位、左右手、落点、防守与身体反馈逐拍写清。
- 近身肘膝动作必须先进入有效距离，不能从远距离直接命中。
- 闪避采用能看见的重心变化和位移，并说明闪避后的反击角度。

### 武器对战

- 锁定持握方式、有效攻击距离、武器刃向或枪口方向。
- 格挡写清武器接触位置与滑移方向，避免武器穿模。
- 武器脱手后写出旋转轨迹、落点和角色空手后的动作策略。

### 摔投与擒拿

- 依次写接触控制、破坏重心、旋转或抬升、离地、落地和后续状态。
- 关节控制必须符合肢体朝向，禁止手臂或腿部反关节穿插。
- 被摔者不能在没有撑地、滚身或起身过程时瞬间站立。

### 追逐

- 建立同一空间坐标和明确前进方向。
- 每次超越、阻截或转向必须有速度差、捷径、障碍或能力依据。
- 镜头切换后保持领跑关系，除非画面展示了交换过程。

### 能力交锋

- 能力必须从固定源点产生，沿身体、武器或空间路径运动。
- 范围能力写清边界、作用对象、扩张速度和结束方式。
- 控制类能力必须表现目标受限的具体部位与可见反馈。

## 能力与特效轨迹

特效必须绑定角色和动作，不可悬空出现：

~~~text
[能力源点] → [沿身体/武器聚集] → [随动作形成的形态] → [三维运动轨迹] → [接触变化] → [余波与消散]
~~~

锁定能量颜色、材质、粒子尺度、速度和作用范围。能力碰撞写清交界面如何推进、弯折、破裂或抵消。特效不能遮住关键肢体、接触点或角色表情。

## 战斗运镜

1. 每个镜头只使用一个核心运镜，并写明跟随目标。
2. 相机运动服务动作方向：横向追击用平移或跟拍，纵深突进用推拉，腾空用升降，摔投用侧面或斜俯展示旋转轴。
3. 重击前可短暂停顿或压缩时间，接触瞬间必须清楚，结果段留出确认时间。
4. 维持 180 度轴线和角色左右关系；越轴必须用明确的过轴镜头建立。
5. 不连续使用同一景别或同一运镜掩盖动作缺失。
6. 高速镜头仍要保留可辨认的起势、接触和结果，不能全程依赖运动模糊。
7. 正反打必须匹配攻击方向、视线和受力方向。
8. 特写只突出关键部位或情绪，不能承担需要展示全身轨迹的大动作。

## 多人战斗

1. 一次只突出一个主要攻防关系，其余人物明确站位、牵制或画外状态。
2. 群攻按威胁顺序切片，禁止所有人同时无序扑向中心。
3. 攻击者进入有效距离后才能发生接触；接触结束后更新人数、站位和行动能力。
4. 友军、平民和禁止破坏物必须纳入攻击轨迹与镜头安全检查。
5. 角色倒地、退场或失去行动能力后，后续镜头的人数必须同步更新。

## 输出前检查

- 是否忠于既定剧情、胜负与伤势。
- 是否每次接触都有起势、防守、受力和结果。
- 是否锁定惯用手、武器、能力源点、颜色和轨迹。
- 是否所有动作都能从上一末态自然发生。
- 是否站位、轴线、距离和场地动线一致。
- 是否为终结与结果确认保留时间。
- 是否没有新增台词、角色、武器、能力或场地物件。

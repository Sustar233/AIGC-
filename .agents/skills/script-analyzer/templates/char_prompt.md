# 角色最小条目模板

只记录用户或剧本可直接确认的信息，未知字段留空或写“待确认”。

```json
{
  "名称": "角色名",
  "别名": [],
  "身份": "",
  "性格与表演": [],
  "OOC限制": [],
  "外貌锚点": [],
  "视觉锚点": {
    "必须保持": [],
    "允许变化": [],
    "禁止变化": []
  },
  "声线提示词": "待确认",
  "状态变化": [],
  "待确认": []
}
```

先沿用当前 `角色.json` 的既有字段与顺序；只在任务确实需要时补充缺失字段。精简人设提示词不得使用推断补齐未知外貌；扩展版也不能与已确认事实冲突。已有正式声线不得覆盖。

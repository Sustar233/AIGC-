# 单元分镜预览图

只在用户选择“带图版”或“多格预览版”时读取。预览图是制作判断用的 Storyboard Preview，不是最终成片关键帧。

## 输入边界

只使用已经完成的当前单元文字分镜，以及本次上下文中已读取的：

- 当前角色视觉锚点与参考图
- 当前场景空间锚点与参考图
- 当前关键道具锚点与参考图
- 项目固定画风

不得重新分析整集剧本、重读完整数据库、重跑剧本分析或加载无关 Skill。缺少的非关键细节保持保守；缺少会导致换脸、空间错乱或道具变形的关键素材时，先标记待确认。

## 代表帧选择

普通带图版每单元只选1个单帧画面，按以下顺序判断：

1. 最能说明剧情结果或关键动作的瞬间。
2. 最能说明核心人物关系和站位的瞬间。
3. 最接近单元主要景别的瞬间。
4. 最能代表主机位与典型构图的瞬间。

普通带图版不制作多格拼贴，也不为每个镜头各生一张图；多格预览版按下方专用流程执行。

## Preview Prompt

按以下顺序组织：

```text
Storyboard Preview，用途为分镜判断，不是最终成片关键帧；
[项目固定画风]；
[代表镜号的景别、主机位、透视与构图焦点]；
[角色必须保持的外观、固定站位、朝向与人物关系]；
[场景固定结构、入口、通道、前中后景与活动区域]；
[关键道具轮廓、结构、持有关系]；
[当前唯一主要动作及明确结果]；
[用动势、方向、透视和构图倾向表达主要运镜趋势]；
16:9 横向单幅画面，纯净画面，无文字、字幕、标注、分格或网格。
```

优先把当前任务已提供的人设图、场景图和道具图作为生成参考；只包含本单元实际需要的最小参考图集合。参考图已经检查过时直接复用，不重复做图片理解。

## 生成与记录

调用 `imagegen` 或当前环境等价的图像生成功能，明确要求只返回 1 张图片；已有本地角色、场景和道具参考图时传入最小必要参考集合。若生成结果提供本地文件，按需创建 `project.json.workflow.storyboard_generation.preview.output_path`，保存图片并在分镜的“预览图”字段记录路径；否则直接返回生成图片，并在字段中记录生成结果说明。

交付时明确说明单图只能表达摄像机位置、景别、透视、运动方向、构图动势和空间层次，不能完整展示动态运镜。


## 多格预览版

用户明确要求完整故事板、多格预览或A/B预览时，使用 `workflow.storyboard_generation.multi_panel_preview`；默认文字版与普通带图版不自动升级。

1. 先完成、校验并展示同一份文字分镜，再生成图片，不以等待生图阻塞脚本交付。
2. 默认两张A/B完整预览，每张覆盖本次脚本全部N镜，同镜号、同布局、同对白与动作边界；A/B为视觉备选，不是两条剧情。张数按用户或配置指定。
3. 采用规整等尺寸矩形网格，每格优先16:9，统一边距和分隔，镜号在画外标识带；格内不加对白字幕或说明文字，剧情必要标识按脚本保留。
4. 逐镜选一个最可读瞬间，明确景别、机位、构图、可见人数、站位和道具状态。不要把单格不同时间点叠在一起；全图角色外观和尺度保持一致。
5. 复用当前已读取的最小参考集合；不重新扫描全剧、不逐像素验收。集中检查镜数、镜序、关键人物与动作连续性，有实质错误才定向修正。
6. 图片保存到配置的 `multi_panel_preview.output_path`。无此字段时使用普通预览目录的“多格预览”子目录。只在交付记录或末尾链接记录图片路径，不写入供视频模型使用的逐镜正文。
7. 调用当前可用的生图工具；需要计费确认时按工具要求执行。不得因历史规则写了“自动”就绕过计费确认。

多格预览用于核对镜头设计，不代表完整动态运镜，也不保证独立视频素材自动帧级匹配。

# AI 视频战斗动作设计（紧凑工作流）

把已锁定的剧情节点转换为清楚、连续、可拍摄的动作链。不得改变角色、台词、能力、武器、胜负、伤势或场景结果。

## 输入

只接收紧凑调用单：

```text
剧情节点与不可改结果：
持续时间：
角色与武器/能力/惯用手：
初始站位、朝向与距离：
场地可交互物与安全区：
终局状态：
禁改项与穿帮风险：
```

缺失信息会影响胜负或动作成立时才请求确认；非关键缺口采用最保守方案，不新增设定。

## 动作设计

- 约 15 秒默认骨架：冲突起势 → 第一轮攻防 → 攻守或位置变化 → 关键动作 → 结果确认。
- 每拍只写一个主因果链：发起者与发力点 → 移动方向 → 接触点/防守 → 受力反馈 → 新末态。
- 起势必须来自上一拍的脚位、重心、手位、武器位置和视线；后续不得无动作复位。
- 进入有效距离后才能发生拳脚、肘膝、抓取、格挡或摔投接触。
- 摔投依次写控制点、破坏重心、旋转轴、离地、落点和落地状态。
- 武器锁定持握手、刃面/铲面/枪口方向、攻击弧线、接触点和脱手去向。
- 能力锁定源点、颜色和路径；释放动作、特效轨迹、接触变化与结果必须在同一因果镜内绑定。
- 每次重击至少说明支撑、力量方向、接触反馈和位移结果；只使用剧本已有环境产生反馈。
- 终结后必须留出结果确认，明确人物位置、伤势、武器和场景状态。

## 多人战斗

- 一次只突出一个主要攻防关系，其余人物保持明确站位或画外状态。
- 群攻按威胁顺序进入有效距离，不让多人同时无序扑向中心。
- 前一组接触结束后更新站位和行动能力，再开始下一组动作。
- 平民、队友、玻璃、桌椅等禁止破坏对象必须位于安全轨迹外。

## 运镜与画风

- 每镜只用一个核心运镜；相机运动跟随动作方向并保持 180 度轴线。
- 起势、接触点和结果必须可辨，不用全程运动模糊掩盖动作。
- 大位移用中景或全景，拳脚和接触用中近景，关键手部或武器点才用特写。
- `project.json.default_visual_style` 和用户画风要求高于通用动作范例。
- 二维少儿动画优先清晰剪影、平面速度线、短促撞击闪光和轻量弹性反馈；不自动加入写实伤口、血液、骨折、肌肉膨胀、3D 体块、游戏镜头或沉重暴力氛围。
- 不为“动作更酷”新增爆炸、碎石、能量、场景破坏或未设定招式。

## 输出

只返回动作方案，交回分镜导演整合：

```markdown
## 战斗动作方案

### 状态锁定
- 时长：
- 初始站位：
- 不可改变结果：
- 禁改项：

### 分段动作链
#### 时间段
- 动作与力学：
- 镜头：
- 环境反馈：
- 末态：

### 连续性末态
- 人物位置与朝向：
- 伤势与体力：
- 武器/能力状态：
- 场景状态：

### 主要穿帮风险
-
```

不要重复原剧本、项目背景、角色长相或完整画风；只写完成动作所需信息。

## 自检

确认：剧情结果未改；每次接触有起势、接触、防守/受力和结果；动作能从上一末态自然发生；站位、轴线、距离、武器和能力源点连续；多人按顺序进入；终结有结果确认；没有新增台词、角色、能力、武器、伤势或场景物件。

# 人设与场景提示词模板

## 人设精简版

```text
[角色名]，[身份与年龄感]，[剧本明确的外貌识别点]，[明确服装]，[明确绑定的武器或能力载体]，自然直立站姿，完整展示身体结构，纯白背景，[项目默认技术风格]。生成4次，每次返回不同图片。
```

## 人设扩展版

```text
[角色名]，[故事身份与人物气质]。外貌：[脸型、眼神、发型发色、肤色、身高体型]。服装：[时代、类别、主色、材质、剪裁]。固定识别点：[3—5项]。能力或关键物：[源点、材质、颜色、携带方式]。自然直立站姿，完整展示身体结构，纯白背景，[项目默认技术风格]。生成4次，每次返回不同图片。
```

## 场景精简版

```text
[场景名]，[剧本直接要求的场景物品与空间关系]，[明确时间条件]，无人物，场景关系清晰。[project.json.workflow.visual_prompt_output.scene_style_suffix] 生成4次，每次返回不同图片。
```

## 场景扩展版

```text
[场景名]，[剧情功能]。空间结构：[前景、中景、背景、出入口和动线]。固定标志物：[建筑、家具、设备或自然地貌]。时间与光源：[明确条件]。可交互物：[剧本需要的物件]。在不改变剧情事实和固定锚点的前提下补充材质、主色、氛围和可复用细节，空间关系清晰，可供后续分镜复用。[project.json.workflow.visual_prompt_output.scene_style_suffix] 生成4次，每次返回不同图片。
```

## 固定锚点

角色至少记录必须保持、允许变化、禁止变化与稳定声线；场景至少记录固定空间元素和允许变化元素；道具至少记录核心轮廓、关键结构，以及已经确认的关键颜色或材质。

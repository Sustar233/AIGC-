# 人设与场景提示词模板

## 人设精简版

```text
[角色名]，[身份与年龄感]，[剧本明确的外貌识别点]，[明确服装]，[明确绑定的武器或能力载体]，自然直立站姿，完整展示身体结构，纯白背景，[项目默认技术风格]。
```

## 人设完整版

```text
[角色名]，[故事身份与人物气质]。外貌：[脸型、眼神、发型发色、肤色、身高体型]。服装：[时代、类别、主色、材质、剪裁]。固定识别点：[3—5项]。能力或关键物：[源点、材质、颜色、携带方式]。自然直立站姿，完整展示身体结构，纯白背景，[项目默认技术风格]。
```

## 场景设定图

```text
[场景名]，[剧情功能]。空间结构：[前景、中景、背景、出入口和动线]。固定标志物：[建筑、家具、设备或自然地貌]。时间与光源：[明确条件]。可交互物：[只写剧本需要的物件]。[项目默认技术风格]，空间关系清晰，可供后续分镜复用。
```

## 固定锚点

角色至少记录姓名、身份、年龄感、发型发色、脸部识别点、体型、服装基准、能力/武器及不可改变元素。场景至少记录名称、区域、空间类型、入口与动线、标志物、主色、光源、剧情功能及不可改变元素。
